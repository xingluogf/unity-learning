# Unity 星辰学院

零基础到精通的 Unity 学习网站，共 **300 节课**、18 大章节，星空主题科技风界面。

- 每课含：学习目标、超详细分步教程（点哪里/写什么/为什么）、完整 C# 代码、常见错误排查、动手练习、小结
- 支持搜索课程、章节筛选、学习进度打卡（localStorage 记录）
- 纯静态 HTML/CSS/JS，无需服务器，双击 `index.html` 即可本地学习

## 在线访问

GitHub Pages：`https://xingluogf.github.io/unity-learning/`

## 目录结构

```
index.html            主站首页（星空主题）
assets/               样式 / 脚本 / 课程数据
lessons/lesson-001~300 300 节课（每课独立 index.html）
build/                课程内容数据（改内容后运行 build_site.py 重新生成）
```
