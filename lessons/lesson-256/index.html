◆路径点巡逻

按点走、到点停。

  1. 【方式1 手动路径点】场景里放几个空对象作路径点（Waypoint1/2/3）。
  2. 【巡逻脚本】
  3. public Transform[] waypoints;
  4. public float speed = 3f;
  5. public float waitTime = 1f;
  6. private NavMeshAgent agent;
  7. private int current = 0;
  8. void Start() { agent = GetComponent<NavMeshAgent>(); GoNext(); }
  9. void GoNext() { agent.SetDestination(waypoints[current].position); }
  10. void Update() {
  11. if (!agent.pathPending && agent.remainingDistance < 1f) {
  12. current = (current + 1) % waypoints.Length;
  13. StartCoroutine(WaitAndGo());
  14. }
  15. }
  16. IEnumerator WaitAndGo() {
  17. agent.isStopped = true;
  18. yield return new WaitForSeconds(waitTime);
  19. agent.isStopped = false;
  20. GoNext();
  21. }
  22. 【说明】到点停 waitTime 再去下一个（循环）。
  23. 【可视化】路径点可加 Gizmo 画出连线（进阶）。
  24. 【测试】AI 沿路径点循环巡逻。
  25. 【完成】“巡逻路线”通了！
💡
Waypoint 巡逻 = 路径点数组 + 按序 SetDestination + 到点停留。循环走。

◆随机与条件巡逻

更多巡逻花样。

  1. 【随机巡逻】从路径点随机选下一个：
  2. int next = Random.Range(0, waypoints.Length);
  3. 【或】在 NavMesh 上随机找可走点：
  4. RandomPointOnNavMesh(origin, range, out pos);
  5. 【实现】RandomPointOnNavMesh 用 NavMesh.SamplePosition：
  6. public static bool RandomPoint(Vector3 center, float range, out Vector3 result) {
  7. for (int i = 0; i < 30; i++) {
  8. Vector3 random = center + Random.insideUnitSphere * range;
  9. NavMeshHit hit;
  10. if (NavMesh.SamplePosition(random, out hit, 1f, NavMesh.AllAreas)) { result = hit.position; return true; }
  11. }
  12. result = Vector3.zero; return false;
  13. }
  14. 【视野切换】巡逻与追击结合（第 211/235 课）：
  15. 发现玩家 → SetDestination(player)（追）；丢失 → 回巡逻。
  16. 【巡逻点绑定敌人】每个敌人自己的路径点数组（可配置）。
  17. 【测试】随机巡逻、发现玩家追击、丢失回巡逻。
  18. 【完成】AI 巡逻“专业”了！
✅
巡逻三式：固定路线（Waypoint 循环）、随机点（SamplePosition）、条件切换（视野追/巡）。

⚠常见错误与排查

⛔
错误：AI 巡逻时卡在某点？
原因：路径点不可达或判断条件不满足
解决：确认路径点在 NavMesh 上可达；remainingDistance 阈值合适；isStopped 正确恢复。
