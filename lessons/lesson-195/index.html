◆URP 后期处理框架

Volume 系统。

  1. 【前提】项目使用 URP 渲染管线（第 260 课）；URP 自带后期处理，无需额外包。
  2. 【开启】URP Asset → Renderer → 勾选【Post Processing】。
  3. 【Volume 框架】后期效果由“Volume”控制（全局或局部）：
  4. 创建空对象 → Add Component → Volume。
  5. 【Volume 设置】Profile（新建或引用）、Is Global（全局勾选，全场景生效）。
  6. 【添加效果】点 Volume 的【Add Override】→ 选择效果（Bloom、Color Adjustments 等）。
  7. 【配置】每个效果有属性，默认值=无效果，改大看变化。
  8. 【Blend】多 Volume 可重叠/渐隐（进房间变暗，进阶）。
  9. 【关键】勾选 Is Global 否则需要在 Trigger 内才生效。
  10. 【注意】后期处理在相机上自动应用，无需额外相机组件。
  11. 【确认】新建 URP 项目默认带后期处理支持（第 260 课创建）。
💡
URP 后期 = Volume（装效果）+ Add Override（选效果）。想加啥加啥。

◆常用效果

先上三个“王牌”。

  1. 【Bloom 泛光】让高亮区域“发光溢散”：亮度超过 Threshold 的部分晕开。
  2. 改 Intensity（1-2 舒服）、Threshold（1 左右）。
  3. 让发光材质/灯光“真的发光”——画面瞬间有质感。
  4. 【Color Adjustments 色彩校正】
  5. Contrast（对比度）、Saturation（饱和度）、Color Filter（色调）。
  6. 做“黄昏暖色调”：Color Filter 选橙色 + 降饱和。
  7. 【Vignette 暗角】四周变暗，聚焦中心：Intensity 0.3、Smoothness 0.5。
  8. 【Depth of Field 景深】（进阶）背景虚化：Focus Distance、Aperture。
  9. 【Film Grain 胶片颗粒】复古噪点。
  10. 【组合示例】“电影感”配方：Bloom(1) + Contrast(10) + Vignette(0.4) + 暖色调。
  11. 【实战】给游戏场景加这套配方，对比前后观感。
  12. 【注意】每加一个效果要看整体，别过度（游戏性优先）。
  13. 【性能】后期效果有开销，移动端选轻量组合（第 266 课）。
  14. 【推荐】Bloom 是性价比最高的“质感提升器”。
✅
电影感三件套：Bloom 发光 + 色调 + 暗角。加完画面“高级”三倍。

⚠常见错误与排查

⛔
错误：后期没效果？
原因：URP 没勾 Post Processing、或 Volume 没勾 Is Global、或效果强度 0
解决：URP Asset 勾 Post Processing；Volume Is Global；调大效果强度。
