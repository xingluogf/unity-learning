◆项目整理与收尾

交付前的“大扫除”。

  1. 【目录】检查项目文件夹规范：Scenes/Scripts/Sprites/Audio/Prefabs 各归其位（第 4 章）。
  2. 【命名】所有对象/资产命名规范（第 45 课），无 Untitled/NewObject。
  3. 【清理】删除无用资产、空对象、测试脚本。
  4. 【检查 Console】无报错无警告（缺失引用、重复 Listener 等）。
  5. 【版本控制】初始化 Git 或备份（第 234 课）。
  6. 【场景】主菜单场景 + 游戏场景 + 结束，全部加入 Build Settings（第 235 课）。
  7. 【必测】完整流程：开始→玩→死→重开→退出，多次无异常。
  8. 【参数】核心手感参数记录下来（速度/跳力/生成间隔）。
  9. 【完成】项目“干净利落”。
  10. 【注意】发布前 Console 必须零报错。
💡
交付三查：目录规范、Console 零错、流程全通。

◆打包发布与复盘

变成“能玩”的成品。

  1. 【打包】File → Build Settings → 选平台（Windows/WebGL/Android）→ Build（第 281-295 章详解）。
  2. 【WebGL】可发布到 itch.io/网页分享（第 285 课）。
  3. 【Windows】生成 .exe 文件夹分享（第 281 课）。
  4. 【测试打包版】运行打包后的游戏再测一遍（别只测编辑器）。
  5. 【复盘 2D 章】
  6. 精灵/图集/相机/角色/物理/碰撞/射线/平台/敌人/道具/视差/射击/弹幕/相机/瓦片/关卡/HUD/存档/音频/对话/跑酷/优化/发布——全章闭环。
  7. 【自我评估】哪些熟练、哪些要补，记录下来。
  8. 【下一步】进入第 14 章 3D 游戏进阶，把 2D 学的（状态机/单例/对象池/协程）迁移到 3D。
  9. 【完成】2D 章毕业，你已能独立做出完整 2D 游戏！
  10. 【奖励自己】玩一把自己的游戏吧！
✅
2D 章毕业 = 完整可玩游戏 + 全流程发布 + 知识复盘。继续向 3D 进发！

⚠常见错误与排查

⛔
错误：打包后游戏异常？
原因：只在编辑器测试过
解决：打包版重新测试；检查 Player Settings（公司名/图标/分辨率）。
