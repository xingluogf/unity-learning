🚀课程导读

Project 窗口管理项目所有文件，是你的“资源仓库”。本课带你把仓库整理得井井有条。

◆Project 窗口基础

找到它，认识它的两栏布局。

  1. Project 窗口默认在编辑器底部，与 Console 并列；点击【Project】标签切换。
  2. 左侧是【文件夹树】：Assets、Packages 等；右侧显示当前文件夹内容。
  3. 【创建资源】：在右侧空白处或文件夹上右键 →【创建 Create】→ 可选脚本（C# Script）、材质（Material）、文件夹（Folder）、场景（Scene）、预制体（Prefab）等。
  4. 【导入资源】：直接把电脑上的图片、模型、音频文件拖进 Project 窗口即可（或菜单【资源 Assets】→【导入新资源】）。
  5. 【双击资源】打开查看：双击材质可预览，双击脚本用代码编辑器打开，双击场景切换到该场景。
  6. 【搜索】：Project 顶部搜索框输入名字过滤；点搜索框左侧可按类型（模型/材质/脚本）过滤，右侧可按标签过滤。
  7. 【定位】：选中某资源按右键 →【在资源管理器中显示】可打开系统文件夹对应位置。
  8. 【拖拽使用】：把材质/脚本/预制体直接拖到 Hierarchy 对象或 Inspector 属性上即可应用。
💡
Resources 文件夹与 Packages 文件夹在左侧会显示；点击 Assets 就能看到你的全部内容。

◆资源筛选与收藏

让找资源更快。

  1. 搜索框右侧点击【类型 Type】下拉：选择“脚本”“材质”“预制体”等可精确过滤。
  2. 在资源上右键 →【收藏 Favorite】可加入顶部收藏列表，常用资源一键直达。
  3. 按住 Ctrl 多选资源可批量移动/删除/复制。
  4. 文件夹内右键可新建子文件夹，保持层级清晰（第 8 课已讲分目录规范）。
  5. 拖拽资源到 Hierarchy 会直接在场景中创建该资源实例。
⚠️
Project 里的删除请选中后按 Delete 或右键删除，让 Unity 统一处理引用，不要用系统资源管理器删。

⚠常见错误与排查

⛔
错误：导入的图片在场景里看不见？
原因：图片需要做成材质或精灵才能显示
解决：图片作为贴图使用时，先创建材质并把贴图赋给材质的 Albedo，再拖材质到物体。

★动手练习

课后小任务（做出来才算真的学会）

  • 在 Assets 下创建 Scenes / Scripts / Materials 文件夹
  • 把一张图片拖进 Project 窗口（可以从电脑上随便找一张）
  • 用类型过滤只看材质
