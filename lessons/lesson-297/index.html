🚀课程导读

“先能玩”——本课把核心玩法做成可运行的原型。

◆角色与操作

“动起来”。

  1. 【项目】新建 2D 项目（第 201 课）或继续之前项目。
  2. 【角色】精灵 + Rigidbody2D + CapsuleCollider2D + 角色脚本（第 205 课完整版）：
  3. 移动/跳跃/翻转/落地检测。
  4. 【手感】调 moveSpeed/jumpForce 直到顺手（第 205 课）。
  5. 【动画】待机/走路/跳跃动画（第 141 课或简单变色）。
  6. 【测试】跑跳流畅、不滑不飘。
  7. 【完成】角色“能玩”。
  8. 【注意】核心手感先调好，后面都是加分。
💡
原型第一步：角色跑跳手感顺。手感是“魂”，先磨它。

◆平台与收集

“关卡”与“目标”。

  1. 【平台】用 Tilemap 画一段平台关（第 217 课）：地面+高低平台+终点旗。
  2. 【金币】金币预制体（第 212 课）：拾取加分+音效+特效。
  3. 【敌人】（可选）放 1-2 个巡逻敌人（第 211 课）。
  4. 【终点】到达终点触发器 → 提示“过关”（先简单提示）。
  5. 【HUD】分数/金币显示（第 219 课）。
  6. 【死亡】掉坑重生到检查点（第 210 课）。
  7. 【测试】完整跑一遍：跳、收集、死、重生、到终点。
  8. 【完成】“能玩”的原型！
  9. 【注意】原型只做“核心”，UI/音效/存档后面加。
  10. 【里程碑验收】角色能跑跳 + 收集金币 = M1 完成。
  11. 【推荐】先单关，能玩再扩展。
✅
原型 = 角色 + 平台 + 收集 + 终点。四样齐=“能玩”。先别加花活。

⚠常见错误与排查

⛔
错误：原型总是“差点意思”？
原因：核心手感/节奏没调好
解决：先专心调“跑跳手感与关卡节奏”，别急着加功能。

  • 实现角色跑跳核心
  • 画一关平台并放金币
  • 做到“能玩”验收
