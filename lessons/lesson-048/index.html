🚀课程导读

游戏里到处是数据：血量、分数、名字、开关状态。变量就是“存数据的小盒子”。

◆什么是变量

变量 = 有名字的“存储盒”。

  1. 变量用来保存一个值，并给这个值起个名字，方便后面使用。
  2. 比如 int score = 0; 表示“我有一个叫 score 的盒子，里面存整数 0”。
  3. 声明变量语法：数据类型 变量名 = 初始值;
  4. 变量名规范：小驼峰（第 45 课），如 playerHealth、score。
  5. 声明后可以在后续代码中读取或修改它。
  6. 先声明再使用，用前要有值。
💡
把变量想象成带标签的抽屉：标签是变量名，抽屉里是数据。

◆常用数据类型

记住这五个最常用的。

  1. 【int】：整数，如 0、-5、100。适合计数、分数、生命值次数。例：int score = 100;
  2. 【float】：小数，如 3.14f、0.5f（注意：float 字面量要加 f 后缀）。适合速度、位置、时间。例：float speed = 5.5f;
  3. 【bool】：布尔，只有 true（真）和 false（假）。适合开关、状态标记。例：bool isDead = false;
  4. 【string】：字符串（文本），用双引号。适合名字、消息。例：string playerName = "英雄";
  5. 【char】：单个字符，用单引号，如 'A'（较少用）。
  6. 【Unity 特有类型】（后续课程）：Vector3（三维向量）、Color（颜色）、GameObject 等。
  7. 声明后可重新赋值：score = 200;（变量可改，常量不行）。
⚠️
float 的数值必须带 f 或 F 后缀，否则编译器报错（如 3.14f）。这是新手最常见报错之一。

在方法里声明的变量叫“局部变量”，只能在该方法内使用；在类里声明的叫“字段”，整个类可用。

⚠常见错误与排查

⛔
错误：报错：Cannot implicitly convert type 'double' to 'float'？
原因：3.14 默认是 double 类型，赋给 float 报错
解决：在数字后加 f：float x = 3.14f;
