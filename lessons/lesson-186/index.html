🚀课程导读

火焰、烟雾、爆炸、星光全是粒子系统。本课创建第一个会动的粒子效果。

◆创建粒子系统

几秒钟出个特效。

  1. 【创建】Hierarchy 右键 → Effects → Particle System，场景出现粒子（默认白点喷射）。
  2. 【组件】Particle System 组件管理粒子，子物体 Camera 是粒子预览相机（别删）。
  3. 【位置】移动对象到想要特效的位置（如火把上方）。
  4. 【立即看效果】播放模式（编辑器顶部 ▶）直接看粒子喷射。
  5. 【核心属性】
  6. Duration：发射持续时间。
  7. Start Lifetime：粒子存活时长。
  8. Start Speed：初始速度。
  9. Start Size：初始大小。
  10. Start Color：粒子颜色。
  11. 【渲染】Renderer 模块：粒子的外观（材质、排序）。
  12. 【播放控制】脚本：ps.Play()/Pause()/Stop()；ps.isPlaying。
  13. 【循环】Looping 勾选则一直喷（火焰）；不勾喷一次（爆炸）。
  14. 【注意】粒子默认是 3D 世界物体，2D 游戏注意 Renderer 排序。
  15. 【素材】粒子材质默认 Default-Particle，可用自定义材质（第 182 课）。
💡
粒子系统 = “批量小精灵”：一口气生成几百个小点，用参数调它们“飞多久/多快/多大/什么色”。

◆做个火焰

经典入门特效。

  1. 新建粒子系统，命名 Fire。
  2. 【形状】Shape 模块选 Cone（锥形），Angle 减小（如 5°），让粒子从底部小口喷出。
  3. 【颜色】Start Color 选橙黄色（火焰色）。
  4. 【大小】Start Size 0.3-0.6，用曲线让粒子越飘越大（第 187 课）。
  5. 【速度】Start Speed 1-3，粒子向上飘。
  6. 【寿命】Start Lifetime 1-2 秒，寿命内升腾消散。
  7. 【循环】Looping 勾选，持续燃烧。
  8. 【渐变】用 Size over Lifetime / Color over Lifetime 模块让火焰“上小下大、底部亮顶透明”（第 187 课）。
  9. 【完成】一个橙色火焰特效！
  10. 【对比】不同参数组合出不同效果：爆炸（不循环+高速度）、烟雾（灰色+慢速+大寿命）、星光（小尺寸+闪烁）。
  11. 【注意】调参数时结合“播放预览”实时查看。
  12. 【保存】特效可存为 Prefab 复用（第 76 课）。
✅
调粒子手感三件套：Shape 定喷射方向、Size/Color 生命周期、Looping 定持续性。

⚠常见错误与排查

⛔
错误：粒子看不见？
原因：Renderer 材质丢失或 Sorting 问题
解决：确认 Renderer 模块有材质；2D 场景调整 Renderer 的 Sorting Layer/Order。
