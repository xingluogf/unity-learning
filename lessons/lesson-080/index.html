🚀课程导读

脚本要操控“别的组件”（刚体、其他脚本、Renderer），全靠 GetComponent。这是最常用的 API 之一。

◆GetComponent 基础

从对象身上“取组件”。

  1. 语法：组件类型 变量 = GetComponent<组件类型>();
  2. 例：Rigidbody rb = GetComponent<Rigidbody>(); 拿到这个对象上的刚体组件。
  3. 之后就能用 rb.AddForce(...) 等操作。
  4. 【获取其他脚本】Player player = GetComponent<Player>(); 访问另一个挂在同一对象上的脚本。
  5. 【获取子/父对象的组件】GetComponentInChildren<T>() / GetComponentInParent<T>()。
  6. 【注意】对象上没有该组件时返回 null，操作会报错。
  7. 【判空】if (rb != null) { rb.AddForce(...); } 安全写法。
  8. 【性能】GetComponent 较快但仍建议缓存到字段（Awake 里获取）。
✅
铁律：GetComponent 放 Awake 里缓存到字段，Update 里直接用缓存，永不每帧 GetComponent。

◆实战：脚本间通信

让两个脚本协作。

  1. 创建脚本 Health：定义 public int hp = 100; public void TakeDamage(int dmg) { hp -= dmg; Debug.Log("剩余HP：" + hp); }
  2. 再创建脚本 Attacker，挂到另一个对象上，在 Update 里检测按键：
  3. if (Input.GetKeyDown(KeyCode.Space)) { Health h = GetComponent<Health>(); if (h != null) { h.TakeDamage(10); } }
  4. 把 Health 和 Attacker 挂到同一个对象上，播放按空格：血量每次减 10。
  5. 若 Health 挂在不同对象，用 public Health target; 在 Inspector 拖入，或用 FindObjectOfType（第 79 课）。
  6. 【核心】组件通信 = GetComponent 拿到对方脚本 → 调用它的 public 方法/字段。
  7. 【高级】用事件/接口解耦（第 68/83 课），让代码更健壮。
💡
跨脚本通信是游戏开发核心能力：血量脚本、攻击脚本、UI 脚本互相配合全靠它。

⚠常见错误与排查

⛔
错误：GetComponent 返回 null 调用报错？
原因：对象上确实没有该组件
解决：先判空 if (comp != null)；或确认组件已添加到对象上。
