◆跟随玩家

小弟“跟班”。

  1. 【脚本 Follower】
  2. public Transform leader; // 玩家
  3. public float followDistance = 2f;
  4. public float stopDistance = 1.5f;
  5. private NavMeshAgent agent;
  6. void Start() { agent = GetComponent<NavMeshAgent>(); }
  7. void Update() {
  8. float dist = Vector3.Distance(transform.position, leader.position);
  9. if (dist > stopDistance) {
  10. // 在玩家身后找目标点（保持跟随距离）
  11. Vector3 toLeader = (transform.position - leader.position).normalized;
  12. Vector3 target = leader.position + toLeader * followDistance;
  13. agent.SetDestination(target);
  14. } else {
  15. agent.isStopped = true;
  16. }
  17. }
  18. 【说明】目标点 = 玩家位置 + 指向自己的方向×跟随距离（站在身后）。
  19. 【距离】玩家走远就追、近了就停。
  20. 【避让】agent 自动避让玩家与障碍。
  21. 【测试】玩家移动，伙伴跟随保持距离。
  22. 【完成】“跟班”上线！
💡
跟随 = 目标点 = 玩家 + 反方向偏移×距离。三行实现“站身后”。

⚠常见错误与排查

⛔
错误：伙伴挡路/挤玩家？
原因：跟随目标点太近
解决：加大 followDistance；给目标加偏移；agent 半径配合。
