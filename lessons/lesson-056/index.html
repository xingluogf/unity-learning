🚀课程导读

有时要在循环中途“刹车”（break）或“跳过这一轮”（continue）。本课两个小关键字解决。

◆break：提前结束循环

找到就停。

  1. break 用于【立即终止整个循环】，跳出循环体继续执行循环后面的代码。
  2. 例：for (int i = 0; i < 10; i++) { if (i == 3) break; Debug.Log(i); } 输出 0,1,2（到 3 就停）。
  3. 常用场景：在数组里“找第一个满足条件的元素”，找到就 break 节省时间。
  4. break 只跳出最近的一层循环（嵌套时注意）。
  5. break 也可用于 switch（第 52 课）。
💡
break 是“整段停”，continue 是“只跳这一轮”——记住这个区别。

◆continue：跳过本轮

不满足条件就跳过。

  1. continue 用于【跳过当前这一轮】，立即进入下一轮循环（继续执行更新语句）。
  2. 例：for (int i = 0; i < 5; i++) { if (i % 2 == 0) continue; Debug.Log(i); } 输出 1,3（跳过偶数）。
  3. 常用场景：只处理满足条件的元素，跳过不满足的。
  4. continue 后本轮的剩余代码不会执行。
  5. 与 break 对比：break 结束整个循环；continue 只跳过当前次。
  6. 【实际应用】在遍历敌人时跳过已死亡的敌人：if (enemy.isDead) continue;
✅
continue 让循环逻辑更清晰：先“排除”不处理的，再处理剩下的。

◆Unity 实战

组合使用。

  1. 新建脚本 BreakDemo，在 Start 里写：
  2. int[] ids = { 1, 2, 3, 4, 5 };
  3. for (int i = 0; i < ids.Length; i++) { if (ids[i] == 3) { Debug.Log("找到 3，停止"); break; } Debug.Log("检查：" + ids[i]); }
  4. 再写 continue 版：for (int i = 0; i < 5; i++) { if (i == 2) continue; Debug.Log("处理：" + i); }
  5. 播放对比两者输出，体会 break 与 continue 的区别。
  6. 【场景】遍历生成敌人，超过上限用 break 停止；跳过已激活的用 continue。
💡
嵌套循环里 break 只跳出内层，想跳出多层可用 return 或标志变量（进阶）。

⚠常见错误与排查

⛔
错误：break 在循环外使用报错？
原因：break 只能用在循环或 switch 内
解决：检查 break 是否误放在循环外。
