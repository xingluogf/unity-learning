🚀课程导读

状态之间的“桥”就是过渡（Transition）。桥的通行规则（条件、时间、打断）决定动画衔接是否自然。

◆创建与配置过渡

连一条“桥”。

  1. 【创建过渡】在 Animator 里右键状态A → Make Transition → 点击状态B，生成 A→B 的箭头。
  2. 【选中箭头】点击箭头，右侧 Inspector 显示过渡属性。
  3. 【Conditions 条件】点【+】添加条件：选择参数、比较方式（Greater/Less/Equals/Not Equals）、填数值。
  4. 例：Speed Greater 0.1 时从 Idle 切到 Walk。
  5. 【Has Exit Time】勾选：当前动画“播完/播到退出时间”才允许过渡（适合动作完成后的衔接）。
  6. 取消勾选：条件满足立即过渡（适合即时响应，如走路立刻变攻击）。
  7. 【Transition Duration】过渡时长：0.1-0.2 秒的交叉融合让切换自然。
  8. 【Transition Offset】从目标动画的哪个时间点开始播（进阶）。
💡
Has Exit Time 勾选=播完才走（完整动作）；不勾=立即走（实时响应）。多数游戏动作选不勾。

◆打断与优先级

让过渡可控。

  1. 【打断】默认过渡可被其他过渡打断。
  2. 【Interruption Source】下拉：None（不可打断）、Current State（被当前状态的其他过渡打断）、Next State 等（进阶）。
  3. 【优先级】多个过渡条件同时满足时，Animator 按“过渡箭头列表的顺序”选择（越靠上越优先）。
  4. 调整顺序：在状态 Inspector 的 Transitions 列表里拖动。
  5. 【Any State 过渡】优先级最高，用于紧急打断（死亡、受击）。
  6. 【优化】条件尽量互斥、减少同时满足的情况，状态机更稳定。
  7. 【过渡预览】点 Play 播放，看过渡是否自然，调整 Duration。
  8. 【常见问题】“动画卡住不动”多因过渡条件永远不满足或 Duration 过大。
  9. 【实战】Idle↔Walk、Walk→Jump、Jump→Idle（落地）、Any→Dead。
✅
过渡三要素：条件（何时切）+ 时长（多自然）+ 打断（谁优先）。调好它们动画才“听话”。

⚠常见错误与排查

⛔
错误：动画切换生硬/卡顿？
原因：Transition Duration 为 0 或过渡未配置好
解决：把 Duration 设 0.1-0.2；确认条件逻辑正确；必要时用 Blend Tree（第 134 课）。
