🚀课程导读

做游戏界面离不开文字。本课解决“UI 文字显示”这一新手高频痛点。

◆导入字体

系统字体也能用。

  1. Windows 系统字体在 C:\Windows\Fonts 目录，如微软雅黑 msyh.ttc、宋体 simsun.ttc（注意 .ttc 兼容性略差，优先 .ttf）。
  2. 或从网上下载免费中文字体（如思源黑体 .otf/.ttf）。
  3. 把字体文件拖进 Project 的 Fonts 文件夹导入。
  4. 选中字体文件，Inspector 显示字体设置：【Font Size】【Character】等。
  5. 【Character】：Dynamic（动态）默认，运行时按需加载字符；Static（静态）需手动指定字符集（旧方案，少用）。
  6. 中文 UI 强烈建议 Dynamic 动态字体，避免“方块字”。
💡
Unity 默认字体（LegacyRuntime.ttf）对中文支持不全，做中文 UI 务必自备中文字体。

◆在 UI 中使用

快速用起来（详细 UI 见第 10 章）。

  1. Hierarchy 右键 → UI → Text（旧版）或 UI → Text - TextMeshPro（推荐，中文更好）。
  2. 选中 Text 对象，在 Inspector 的【Text】框里输入中文“你好，Unity！”。
  3. 若显示方块 □□：把字体 Font 字段设为导入的中文字体，或调整字体资源。
  4. TextMeshPro 首次使用会提示“导入 TMP Essentials”，点【Import TMP Essentials】确认导入。
  5. TextMeshPro 的字体设置：选中字体资源 → Create TMP Font Asset 生成 TMP 字体资产。
  6. 调好字号【Font Size】与颜色【Color】。
  7. 场景里立即显示中文。
⚠️
TextMeshPro 比旧版 Text 强大得多，建议全部课程都用 TextMeshPro 系列。

⚠常见错误与排查

⛔
错误：UI 文字全是方块 □□□？
原因：字体不支持中文或字体未正确引用
解决：换用支持中文的字体（微软雅黑/思源黑体），并在文字组件里指定该字体。
