◆整体设计

一个爆炸的“全流程”。

  1. 【需求】玩家按 F 丢手雷，命中地面触发：爆炸特效+光+冲击波+屏闪+震动+爆炸音效。
  2. 【模块规划】
  3. ① 手雷：刚体抛射物 + 拖尾。
  4. ② ExplosionFx：爆炸粒子预制体（第 197 课）。
  5. ③ FeedbackSystem：统一触发屏幕反馈与音效。
  6. ④ ObjectPool：特效对象池（第 198 课）。
  7. 【准备】确认 AudioManager、ObjectPool、CameraShake（第 198 课）都就绪。
  8. 【注意】先规划再动手，避免改来改去。
  9. 【结构】所有系统用单例（第 86 课），全局可调。
  10. 【场景】放一个测试地面与几个靶子。
💡
综合项目先列“模块清单”，逐个实现再拼装——这是真实开发的节奏。

◆实现与整合

让爆炸“一步到位”。

  1. 【手雷】创建球体预制体：Rigidbody + 脚本 Grenade：
  2. public float fuseTime = 2f;
  3. void Start() { GetComponent<Rigidbody>().AddForce(Camera.main.transform.forward * 15f, ForceMode.Impulse); }
  4. void Update() { fuseTime -= Time.deltaTime; if (fuseTime <= 0) Explode(); }
  5. void Explode() {
  6. // 1. 爆炸特效（对象池）
  7. ObjectPool.Instance.GetExplosion(transform.position);
  8. // 2. 爆炸音效
  9. AudioManager.Instance.PlaySFX(explosionSound);
  10. // 3. 屏幕反馈
  11. FeedbackSystem.Instance.Shockwave();
  12. // 4. 销毁
  13. Destroy(gameObject);
  14. }
  15. 【爆炸特效池】预创建 10 个爆炸粒子预制体循环复用。
  16. 【冲击波】FeedbackSystem 里做屏幕震动 + 红闪（第 196-198 课）。
  17. 【爆炸伤害】范围内敌人扣血（Physics.OverlapSphere，第 94 课）。
  18. 【音效】爆炸音效+延时回响（协程）。
  19. 【测试】按 F 丢雷，完整流程体验：飞行→爆炸→光→震→响→伤敌。
  20. 【优化】检查对象池复用、粒子上限、音效不爆。
  21. 【完成】特效章+音频章毕业！你已能做出“有声有色”的游戏。
✅
一个爆炸 = 4 个系统协作（特效池+音频+反馈+伤害）。学会这套“系统协作”，就是高级开发者。

⚠常见错误与排查

⛔
错误：手雷穿墙？
原因：没碰撞体或速度过快穿透
解决：确认手雷有 Collider+Rigidbody；高速物体用 Continuous 碰撞检测（第 93 课）。
