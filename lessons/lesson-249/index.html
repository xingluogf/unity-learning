◆角色数据结构

数据与逻辑分离。

  1. 【PlayerStats 组件】集中管理角色数值：
  2. [System.Serializable] public class PlayerStats : MonoBehaviour {
  3. public int maxHp = 100; public int hp;
  4. public int maxStamina = 100; public float stamina;
  5. public int level = 1; public int xp;
  6. public float moveSpeed = 6f; public float damage = 20f;
  7. public event System.Action OnHpChanged;
  8. public void Start() { hp = maxHp; stamina = maxStamina; }
  9. public void TakeDamage(int dmg) { hp = Mathf.Max(0, hp - dmg); OnHpChanged?.Invoke(); }
  10. public void Heal(int amount) { hp = Mathf.Min(maxHp, hp + amount); OnHpChanged?.Invoke(); }
  11. }
  12. 【单一职责】一个组件管”数值“，移动/攻击组件管”行为“，互不干扰。
  13. 【事件】数值变化发事件，UI/音效订阅（第 167 课）。
  14. 【访问】GetComponent<PlayerStats>() 读取。
  15. 【升级】AddXp 升级提升属性。
  16. 【注意】数值集中一处，避免散落各脚本。
  17. 【完成】角色数据”有家“了！
💡
角色系统 = 一个 PlayerStats 组件集中数值 + 事件通知变化。数据归一。

⚠常见错误与排查

⛔
错误：体力负数/无限？
原因：没 Clamp 或恢复逻辑漏
解决：消耗/恢复都 Clamp 到 [0, maxStamina]；状态一致。
