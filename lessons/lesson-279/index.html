🚀课程导读

◆资源大扫除

找出“胖子”。

  1. 【找大文件】Project 窗口右上角 → 菜单选“三：竖排按钮 → Show Project Size”（或商店工具）。
  2. 【按大小排序】找到最大贴图/音频/模型。
  3. 【压缩】大贴图压尺寸/格式（第 266 课）。
  4. 【找未用资源】Build Report 工具（商店“Build Report Tool”）列出未用资源。
  5. 【删除】确认无用再删（Ctrl+Del）。
  6. 【检查】Resources 里的每样东西都进包：能不放就别放。
  7. 【图集】UI 精灵打图集（第 203 课）。
  8. 【纹理】重复/近似纹理合并。
  9. 【完成】包“瘦身”。
  10. 【注意】删之前确认没被引用（否则报错）。
  11. 【目标】包体减到合理大小。
💡
资源审计 = 按大小排序找胖子 + Build Report 找没用 + 压缩/删除。

◆内存审计

内存“热点”在哪。

  1. 【Profiler Memory】录制运行时看内存分布：
  2. 纹理/音频/网格/动画/GC 各占多少。
  3. 【热点】找出占内存最大的资源类型与具体资产。
  4. 【优化】
  5. 大贴图压缩/关 Mipmap。
  6. 长音频 Streaming（第 266 课）。
  7. 场景资源按需加载（第 266 课）。
  8. 【GC 堆】看 GC 堆大小与增长（泄漏检查）。
  9. 【真机】真机长时间运行看内存曲线（是否稳定/泄漏）。
  10. 【峰值】记录峰值内存（内存不足闪退风险）。
  11. 【完成】内存“透明”。
  12. 【注意】峰值内存别超设备限制。
  13. 【推荐】发布前必做资源+内存审计。
✅
审计收尾 = 资源瘦身 + 内存透明 + 峰值可控。发布前双查。

⚠常见错误与排查

⛔
错误：删除资源后报引用错误？
原因：资源还在被引用
解决：删除前用“Find References in Scene”（右键）确认无引用；或改用禁用。
