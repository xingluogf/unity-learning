“60 帧稳定”比“偶尔 120”体验好。本课学帧率管理。

◆目标帧率设置

锁帧还是放帧。

  1. 【设置】Application.targetFrameRate = 60;
  2. 【说明】限制最大帧率：省电、稳定、防过热。
  3. 【垂直同步】QualitySettings.vSyncCount：0=关、1=60Hz 同步。
  4. 【关系】vSyncCount>0 时 targetFrameRate 效果受限。
  5. 【PC】开垂直同步避免画面撕裂（60 或 144 看显示器）。
  6. 【移动端】vSyncCount=0 + targetFrameRate=60（或 30）最可控。
  7. 【高刷屏】高刷屏（120Hz）可设 120（进阶）。
  8. 【注意】帧率设置要在游戏启动时（Awake）执行。
  9. 【完成】帧率“可控”。
  10. 【测试】在 Profiler 看实际帧率。
  11. 【推荐】先 60，性能不足降 30。
💡
帧率管理 = targetFrameRate 锁上限 + vSyncCount 控同步。两参数管流畅。

◆自适应帧率

“按设备调”。

  1. 【需求】低配设备自动降画质/帧率。
  2. 【检测帧率】每帧统计平均 FPS：
  3. float fps;
  4. void Update() { fps = 1f / Time.deltaTime; }
  5. 【检测耗时】或直接看帧时间是否超目标。
  6. 【自适应降级】帧率连续低于 30 时：
  7. 降低画质（QualitySettings 等级）、关后期、降分辨率。
  8. 【实现】
  9. if (fps < 30f && quality > 0) {
  10. quality--;
  11. QualitySettings.SetQualityLevel(quality);
  12. }
  13. 【恢复】帧率恢复后逐步提升（防抖动，加延迟）。
  14. 【设备分级】首次运行按硬件/分辨率选画质档位（进阶）。
  15. 【注意】别频繁切换画质（卡顿感）。
  16. 【完成】“聪明”的帧率管理。
  17. 【测试】低配模拟下看自动降级。
  18. 【进阶】动态分辨率（URP Render Scale）。
✅
自适应 = 测帧率 → 连续低就降画质。高端机全开、低端机保帧。

⚠常见错误与排查

⛔
错误：锁 60 却跑 30？
原因：垂直同步或设备限制
解决：确认 vSyncCount=0；targetFrameRate 在 Awake 设置；检查硬件/编辑器限制。
