🚀课程导读

Shader（着色器）是 GPU 上运行的“绘画程序”。本课把最常用的标准着色器参数讲透。

◆什么是 Shader 与渲染模式

先把概念和模式理清。

  1. Shader = 告诉 GPU“怎么把物体画出来”的程序。材质（Material）= Shader + 参数（颜色、贴图）。
  2. 在材质面板顶部是【Shader】下拉框：当前为 Standard（标准）。
  3. 点击【Rendering Mode 渲染模式】下拉：
  4. 【Opaque 不透明】：默认，完全不透明。
  5. 【Cutout 镂空】：按透明度阈值裁剪，适合铁丝网、叶子（边缘硬）。
  6. 【Fade 淡出】：整体淡出，半透明（不适合复杂遮挡）。
  7. 【Transparent 透明】：真实半透明，适合玻璃、水面。
  8. 改变渲染模式后，下方会多出【Surface Options】等选项。
💡
做玻璃/水面先切 Transparent 模式，再做半透明物体才有效。

◆核心参数组合实战

用贴图+参数做真实材质。

  1. 准备一张纹理贴图（第 38 课会讲导入），拖到 Albedo 的方框里。
  2. 【Metallic Map】：把一张“金属度贴图”拖入（黑白图，白=金属）。没有就拖动滑条直接调数值。
  3. 【Smoothness】：数值或贴图控制光滑度。
  4. 【Normal Map】：拖入法线贴图，让表面有凹凸光影。
  5. 【Emission】：勾选并点色块，设发光颜色与强度（可拖入自发光贴图）。
  6. 【Tiling 平铺】与【Offset 偏移】：控制贴图的重复次数与位置，如 Tiling X=2 让贴图重复 2 次。
  7. 最后把所有参数组合，场景里实时预览效果。
⚠️
贴图种类多时注意拖对槽：颜色贴图进 Albedo、法线贴图进 Normal Map、金属贴图进 Metallic，别拖混。

⚠常见错误与排查

⛔
错误：物体显示紫红色/粉色？
原因：Shader 丢失或出错
解决：常见于 Shader 不存在/损坏。重建材质或把 Shader 重新设为 Standard 即可。

★动手练习

课后小任务（做出来才算真的学会）

  • 做一个半透明玻璃材质（Transparent + 低 Smoothness + 浅色 Albedo）
  • 做一个自发光霓虹灯材质
  • 给地砖贴图设置 Tiling=2 观察重复
