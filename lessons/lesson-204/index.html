◆相机基础设置

2D 相机的标准配置。

  1. 【正交】确认 Main Camera 是 Orthographic（第 201 课）。
  2. 【Size】相机 Size 决定垂直视野（世界单位）。
  3. 【比例关系】水平视野 = Size × 2 × 宽高比（9:16 竖屏时水平视野窄）。
  4. 【背景】Background 设场景基调色。
  5. 【Culling Mask】渲染哪些层（默认全部）。
  6. 【目标纹理】可不设（默认屏幕）。
  7. 【相机移动】2D 相机的“跟随”是平移 Transform（第 216 课）。
  8. 【多相机】2D 可用多个相机做分层（背景/前景，进阶）。
  9. 【注意】相机不要旋转（2D 无旋转意义）。
💡
2D 相机 = 正交 + Size + 背景色 + 代码平移。四件事。

◆Pixel Perfect 像素完美

像素风“锐利”。

  1. 【问题】像素风游戏分辨率不对齐时，像素“糊/抖”。
  2. 【Pixel Perfect Camera 组件】自动把渲染对齐到整数像素网格，画面锐利。
  3. 【添加】给 Main Camera 加组件【Pixel Perfect Camera】（Package 里找，URP 自带）。
  4. 【属性】
  5. Assets PPU：精灵的 PPU 值（如 16/32）。
  6. Reference Resolution：参考分辨率（如 640x360）。
  7. Upscale Render Texture：上采样渲染。
  8. 【效果】相机缩放自动对齐像素网格，画面锐利不糊。
  9. 【限制】像素完美会限制相机移动的最小粒度（注意跟随平滑）。
  10. 【分辨率适配】Game 视图切不同分辨率看画面是否清晰。
  11. 【注意】Pixel Perfect 与后处理（Bloom）可能冲突，酌情取舍。
  12. 【完成】像素风画面“丝般顺滑”。
  13. 【注意】非像素风游戏不需要 Pixel Perfect，普通正交即可。
✅
像素游戏上 Pixel Perfect：画面立刻“锐利”百倍。

⚠常见错误与排查

⛔
错误：像素画面抖动/模糊？
原因：没开 Pixel Perfect 或 PPU 不匹配
解决：加 Pixel Perfect Camera；把 Assets PPU 设为精灵的 PPU。
