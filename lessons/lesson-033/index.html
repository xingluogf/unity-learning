🎯本节学习目标

  • 把一个对象制作成预制体
  • 在场景中摆放多个实例
  • 修改模板并观察实例同步更新

🚀课程导读

光说不练假把式，本课亲手走一遍预制体全流程。

◆创建预制体

两种方式任选。

  1. 方式一：在场景中做好一个“敌人”（Cube + 红色材质 + Rigidbody + 自己的脚本），选中它。
  2. 把它从 Hierarchy 直接拖到 Project 窗口的 Prefabs 文件夹里。
  3. 拖入后 Hierarchy 里的对象名字变蓝色，表示“它已成为该预制体的实例”。
  4. Project 里多了一个 .prefab 文件（默认以对象名命名，可重命名）。
  5. 方式二：在 Project 里右键 → Create → Prefab，先建空模板，再双击进入编辑模式搭内容。
  6. 推荐方式一（先搭好再转预制体）。
💡
名字变蓝 = 已连接预制体。若名字变红说明引用断裂，需重新连接。

◆使用与批量修改

实例化 + 统一修改。

  1. 在场景中直接拖动 Project 里的 Enemy 预制体到 Hierarchy/场景，一次生成一个实例，连拖 5 个。
  2. 移动这些实例到不同位置，它们是独立摆放的。
  3. 现在双击 Project 里的 Enemy 预制体，进入【预制体编辑模式】（场景变灰，出现“回到场景”箭头）。
  4. 在编辑模式里把材质换成绿色，点左上角【←】回到场景。
  5. 查看场景里所有敌人实例：全部变绿了！这就是“模板改一处、实例全更新”。
  6. 选中某个实例，在 Inspector 顶部出现【Open / Select / Overrides】按钮：Overrides 显示该实例相对模板的差异。
  7. 删除 Project 里的预制体文件，场景中的实例会断开（变红），需谨慎。
⚠️
编辑预制体后记得点“返回场景”；若场景中有“Apply”按钮，点它可把实例改动应用回模板。

⚠常见错误与排查

⛔
错误：拖预制体进场景时，场景里出现两个重叠的物体？
原因：可能预制体内部已有物体，又被重复添加
解决：先删除场景中的旧实例，再重新拖入；检查预制体内部结构。

★动手练习

课后小任务（做出来才算真的学会）

  • 做一个 Enemy 预制体（含 3 个组件以上）
  • 在场景中放 5 个实例并错开位置
  • 修改模板颜色，验证全部实例同步
