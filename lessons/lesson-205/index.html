◆2D 移动

左右 + 翻转。

  1. 【准备】把角色精灵放入场景，加 BoxCollider2D + Rigidbody2D（第 206-207 课），加脚本 PlayerController。
  2. 【移动代码】
  3. public float moveSpeed = 5f;
  4. private Rigidbody2D rb;
  5. private SpriteRenderer sr;
  6. void Start() { rb = GetComponent<Rigidbody2D>(); sr = GetComponent<SpriteRenderer>(); }
  7. void Update() {
  8. float h = Input.GetAxisRaw("Horizontal");
  9. rb.velocity = new Vector2(h * moveSpeed, rb.velocity.y);
  10. if (h > 0) sr.flipX = false;
  11. else if (h < 0) sr.flipX = true;
  12. }
  13. 【说明】GetAxisRaw 返回 -1/0/1（无平滑）；velocity 直接设 X 速度。
  14. 【朝向】按移动方向 flipX 翻转精灵。
  15. 【注意】2D 刚体用 Rigidbody2D，速度用 rb.velocity（Vector2）。
  16. 【测试】左右键移动、精灵跟随翻转。
  17. 【优化】跳跃/移动都用 FixedUpdate 里的物理（第 91 课）更稳（velocity 设物理量）。
  18. 【注意】别在 Update 里改 rb.velocity 再被物理覆盖，保持一致。
💡
2D 移动 = GetAxisRaw 方向 × 速度 → rb.velocity.x；翻转 = sr.flipX。

◆2D 跳跃

按下空格跳起。

  1. 【跳跃代码】
  2. public float jumpForce = 8f;
  3. public Transform groundCheck; public LayerMask groundLayer;
  4. void Update() {
  5. bool grounded = Physics2D.OverlapCircle(groundCheck.position, 0.1f, groundLayer);
  6. if (Input.GetKeyDown(KeyCode.Space) && grounded) {
  7. rb.velocity = new Vector2(rb.velocity.x, jumpForce);
  8. }
  9. }
  10. 【原理】给刚体一个向上速度（而非 AddForce），跳跃高度可预测。
  11. 【落地检测】脚下一个小 Circle 检测地面：
  12. 创建子物体 GroundCheck 放脚底；LayerMask 指向“Ground”层（地面设 Ground 层）。
  13. 【防连跳】只有 grounded 时才允许跳。
  14. 【重力】Rigidbody2D 的 Gravity Scale=1（可调跳跃手感）。
  15. 【手感】jumpForce 8-10、moveSpeed 5-8 常见；Velocity 法高度稳定。
  16. 【可变跳跃】（进阶）按住跳得更高：松开时若上升中把 velocity.y 减半。
  17. 【测试】跑+跳+落地检测正常。
  18. 【注意】跳跃要“落地检测”防空中连跳与浮空。
✅
2D 跳跃 = 落地检测（脚底圆圈）+ 直接设向上速度。稳定可控。

⚠常见错误与排查

⛔
错误：角色一直“飘”着不落地？
原因：Rigidbody2D 没启用重力或没有 Collider2D
解决：确认 Rigidbody2D Gravity Scale>0；有 BoxCollider2D 与地面碰撞。
