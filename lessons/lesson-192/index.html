🚀课程导读

阴影给物体“落地感”。本课讲清实时阴影与烘焙阴影的取舍。

◆实时阴影设置

动态物体的影子。

  1. 【开启】灯光 Inspector 的【Shadows】下拉：No Shadows / Hard Shadows（硬边）/ Soft Shadows（软边）。
  2. 【原理】实时阴影用“阴影贴图”渲染，物体每帧重新计算（动态）。
  3. 【Quality 质量】Project Settings → Quality：Shadow Resolution（低/中/高/超高）、Shadow Cascades 等。
  4. 【Shadow Distance】灯光阴影距离：超过该距离的物体不投影（省性能）。
  5. Quality 设置的 Shadow Distance 可在每个灯光的 Inspector 覆盖。
  6. 【软阴影】Soft Shadows 边缘模糊更真实，但更耗。
  7. 【性能】实时阴影最耗，控制距离与质量。
  8. 【注意】半透明/双面材质阴影表现需专门处理（进阶）。
💡
实时阴影三旋钮：类型（Hard/Soft）、分辨率、距离。调好性能与画质的平衡。

◆烘焙阴影（光照贴图）

静态场景的高质量影子。

  1. 【概念】烘焙（Bake）：把光照结果“烤”进贴图，运行时零计算，质量高。
  2. 【设置】静态物体勾选【Static】；灯光 Mode 设为【Mixed】或【Baked】。
  3. 【烘焙】Window → Rendering → Lighting → Scene 页签 → 点【Generate Lighting】生成。
  4. 【结果】静态物体的光影被烘进光照贴图，运行时不计算。
  5. 【混合 Mixed】灯光：静态物体烘焙 + 动态物体实时（常用方案）。
  6. 【光照贴图尺寸】Lightmap Resolution 控制细节/内存。
  7. 【区域光】只在烘焙模式生效（第 191 课）。
  8. 【适用】室内场景、低性能设备大量用烘焙。
  9. 【注意】烘焙后改物体位置/灯光要重新烘焙，否则影子错位。
  10. 【实战】室内场景全部静态，点 Generate Lighting，观察影质量提升与运行流畅。
  11. 【推荐】静态物多、性能紧张就烘焙；动态角色靠实时光。
✅
阴影策略：静态场景烘焙（高质量零开销）、动态物体实时。混合最实用。

⚠常见错误与排查

⛔
错误：烘焙后阴影没变/错位？
原因：物体没勾 Static 或没重新烘焙
解决：静态物体勾 Static；灯光 Mode 设 Mixed；重新 Generate Lighting。
