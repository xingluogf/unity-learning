◆3D 项目与环境

3D 世界的“地基”。

  1. 【创建】Unity Hub → New Project → 选【3D Core】模板。
  2. 【3D 默认】场景自带 Directional Light + Main Camera（透视投影）。
  3. 【坐标】3D 三维坐标：X（右）、Y（上）、Z（前）。旋转用四元数（Quaternion，第 62 课）。
  4. 【单位】1 单位 = 1 米（物理常用）。
  5. 【场景】新建场景 Level1，规划目录（第 4 章）。
  6. 【地面】创建 Plane（平面）或 Cube 压扁做地面。
  7. 【测试物】放几个 Cube/Sphere 测试光照与碰撞。
  8. 【相机】Main Camera 透视投影（Perspective）即 3D 标准。
  9. 【渲染管线】URP 更现代（第 260 课），本系列 3D 用 URP。
  10. 【注意】3D 用 Rigidbody（非 2D）、Mesh Renderer（非 SpriteRenderer）。
  11. 【完成】3D 环境就绪！
💡
3D 与 2D 核心区别：三维坐标 + 透视相机 + 网格渲染 + 3D 物理。一套新工具。

◆搭建基础 3D 场景

灯光 + 地面 + 物体。

  1. 【灯光】保留 Directional Light，旋转到 45° 打光（第 191 课）。
  2. 【地面】Plane 上放默认材质（或贴纹理）。
  3. 【物体】放几个几何体（Cube 做房子、Sphere 做球）。
  4. 【材质】给物体上材质（第 188-190 课）。
  5. 【天空盒】换一个天空盒（第 193 课）增加氛围。
  6. 【碰撞】确认地面有 Collider（Plane 自带）、物体有 Collider。
  7. 【相机视角】调整相机位置/角度看到场景。
  8. 【移动相机】Scene 视图右键 WASD 飞（Q/E 升降）快速查看。
  9. 【游戏视图】切 Game 视图预览。
  10. 【保存】保存场景 Level1。
  11. 【完成】一个 3D 场景“立”起来了！
✅
3D 场景五件套：地面、物体、材质、灯光、天空盒。五样凑齐画面就“立”。

⚠常见错误与排查

⛔
错误：场景全黑/物体看不见？
原因：灯光缺失或相机朝向不对
解决：确认有 Directional Light 且朝向场景；相机看向场景。
