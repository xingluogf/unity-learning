🚀课程导读

“受伤屏幕变红”“被击中闪白”——全屏特效增强反馈。本课用 UI 与后期组合实现。

◆受伤红屏与全屏闪

屏幕级反馈。

  1. 【受伤红屏】Canvas 顶层全屏 Image（红色、半透明、锚点拉伸），默认 Alpha 0。
  2. 【脚本 DamageFlash】
  3. public Image redScreen; // 全屏红色
  4. public float flashTime = 0.2f;
  5. public void FlashRed() { StartCoroutine(Flash()); }
  6. IEnumerator Flash() {
  7. redScreen.color = new Color(1, 0, 0, 0.6f);
  8. while (redScreen.color.a > 0f) {
  9. Color c = redScreen.color; c.a -= Time.deltaTime / flashTime; redScreen.color = c;
  10. yield return null;
  11. }
  12. }
  13. 【调用】玩家受伤时：damageFlash.FlashRed();
  14. 【白色闪】同理用白色 Image 做“被击中/闪光弹”全屏白。
  15. 【注意】全屏 Image 要在最上层（Hierarchy 最后），Block Raycast 可关。
  16. 【性能】全程只改颜色 alpha，零开销。
💡
受伤红屏 = 全屏半透明 Image + 协程淡出。一行调用、即时反馈。

◆黑白滤镜与低速时间

“濒死/慢动作”感。

  1. 【黑白】用 Volume 的 Color Adjustments：Saturation 拖到 -100 = 黑白。
  2. 脚本控制饱和度：
  3. public Volume volume; ColorAdjustments ca;
  4. void Start() { volume.profile.TryGet(out ca); }
  5. public void SetGrayscale(float s) { ca.saturation.value = s; }
  6. 【低速时间】濒死/慢动作：Time.timeScale = 0.3f（第 162 课），配合降饱和营造“危险”感。
  7. 【组合应用】血量低时：闪红 + 渐变黑白 + 心跳声。
  8. 【屏幕震动】配合第 198 课 Camera Shake，反馈更强烈。
  9. 【其他全屏特效】
  10. 被冰冻：蓝色全屏 Image + 缓慢淡入。
  11. 毒：绿色边缘。
  12. 【注意】后期效果要“可恢复”：结束后把饱和/时间调回正常。
  13. 【完整】做“低血量警告”系统：血<30% 时屏幕边缘泛红 + 呼吸闪烁。
  14. 【验证】扣血、濒死、恢复全程测试。
  15. 【完成】屏幕特效让游戏“会说话”。
✅
屏幕特效 = 全屏 Image（闪红/白）+ 后期调参（黑白）+ timeScale（慢动作）。反馈拉满。

⚠常见错误与排查

⛔
错误：红屏一直不消失？
原因：协程被中断或 Alpha 没减到 0
解决：确认协程正确执行；减到 0 后设 color.a=0 兜底。
