🚀课程导读

“火把既发光又冒烟”“魔法球发光”——粒子 + 灯光的黄金组合。本课做发光特效。

◆火焰 + 光晕组合

火光要点亮周围。

  1. 【火焰粒子】做一个火焰粒子（第 186-187 课），放在火把位置。
  2. 【加光】火焰位置加一个 Point Light：橙黄色、Range 5、Intensity 2。
  3. 【效果】火焰周围被照亮，明暗随火光闪烁（进阶：代码随机光强模拟闪烁）。
  4. 【光晕感】粒子 Start Color 用带半透明的亮黄白粒子做“内焰”，外层橙色。
  5. 【闪烁】给 Light Intensity 加随机：
  6. IEnumerator Flicker() { while(true) { light.intensity = Random.Range(1.8f, 2.4f); yield return new WaitForSeconds(0.1f); } }
  7. 【完成】一个“会发光的火把”。
  8. 【适用】蜡烛、营火、霓虹、魔法阵。
💡
火光 = 粒子（看得见的火焰）+ 点光（照亮周围）+ 随机闪烁（活起来）。

◆激光与发光特效

科幻感光效。

  1. 【激光束】用“拉伸的发光体”做激光：细长 Cube + Unlit 发光材质（不受光、自己亮，第 188 课）。
  2. 或粒子 Stretch（Render Mode 拉伸）拉成长条 + Emission 发光材质。
  3. 【发光材质】材质用 Unlit + Emission 亮色，或 Standard 开 Emission（第 189 课）。
  4. 【光晕 Sprite】用一张“径向渐变”发光贴图（PhotoShop 画个柔光圆）做光晕：Billboard 粒子或 UI 放光源处。
  5. 【屏幕空间光晕】Post Processing 的 Bloom（泛光，第 195 课）让亮的地方“发光”，光效之王。
  6. 【魔法球】球体 + 自发光材质 + 周围粒子环绕（Circle Shape + 轨道旋转）+ 点光。
  7. 【组合】把以上组合成一个“魔法传送门”特效：环状粒子 + 发光盘 + 点光 + Bloom。
  8. 【注意】发光物体通常用 Unlit/自发光，配合 Bloom 才有“光感”。
  9. 【性能】发光贴图 + Bloom 是主流方案，比实时灯光省。
  10. 【完成】你的场景有“科幻感”了！
✅
发光三件套：Unlit/自发光材质 + 发光贴图 + Bloom 泛光。电影感光效的钥匙。

⚠常见错误与排查

⛔
错误：发光物体不发光？
原因：材质没开 Emission 或用了受光材质但没光
解决：用 Unlit 材质或 Standard 开 Emission；亮度调高；配合 Bloom。
