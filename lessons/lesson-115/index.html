🚀课程导读

Unity 推出了新一代输入系统（Input System），与旧的 Input Manager 并存。本课帮你搞清怎么选、怎么切换。

◆两套系统对比

先认清差异。

  1. 【旧版 Input Manager】用 Input.GetAxis/GetKey 等（我们前几课用的）：简单、资料多、开箱即用，多数教程沿用。
  2. 【新版 Input System】通过 Package Manager 安装：支持手柄/触摸/键鼠统一抽象、配置化映射、性能更好、代码异步。
  3. 【旧版缺点】手柄/多平台支持弱、无法配置复杂映射、虚拟按键少。
  4. 【新版缺点】上手曲线陡、API 与旧教程不同、需要额外学习。
  5. 【兼容模式】新版提供“Both”模式：同时启用新旧两套（适合学习过渡）。
  6. 【选择建议】新手入门阶段用旧版（资料多、简单）；做多平台/专业项目用新版。
💡
本教程以旧版 Input 为主（最通用、资料最全），你完全够用；新版作为进阶了解。

◆启用新版与切换

想用新版怎么办。

  1. 【安装】Package Manager → 搜 Input System → Install（第 43 课装包方法）。
  2. 安装后 Unity 会弹窗询问：使用新输入系统？建议选【Yes】或【Both】。
  3. 【手动切换】Edit → Project Settings → Player → Active Input Handling：Input Manager (Old) / Input System Package (New) / Both。
  4. 【切换影响】切到 New 后，Input.GetAxis 等旧代码会报错；切回 Old 恢复。
  5. 【Both 模式】新旧并存：旧代码可跑，新版也能用。
  6. 【新版代码示例】（进阶了解）：用 PlayerInput 组件或 InputAction 资产，事件回调处理输入。
  7. 【建议】先学完旧版基础，再接触新版。切换前备份项目。
⚠️
切换输入系统前保存项目；用 Both 模式最稳妥，避免旧代码报错。

⚠常见错误与排查

⛔
错误：切到新输入后 Input.GetAxis 报错？
原因：新系统禁用旧 API
解决：把 Active Input Handling 设为 Both 或 Old；或改用新版 API。
