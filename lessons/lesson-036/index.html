🚀课程导读

很多美术资源需要外部制作后导入。本课教你正确地把 3D 模型请进 Unity。

◆支持的格式与准备

先认识格式。

  1. Unity 最推荐的模型格式：【FBX】（.fbx），兼容性最好，支持动画、材质、骨骼。
  2. 其次是【OBJ】（.obj）：只含几何信息，无动画、无骨骼，适合静态物件。
  3. 其他如 .3ds、.dae、.blend 也可（需开启对应支持）。
  4. 获取模型：美术用 Blender/Maya/3ds Max 导出 FBX；或从 Asset Store / 网络免费模型库下载。
  5. 【注意事项】：模型命名用英文；导出前把模型“归零”（位于原点、尺寸适中）；单位保持一致。
💡
不会建模也能学：先下载免费 FBX 模型练手，动手最重要。

◆导入模型

把文件拖进 Unity。

  1. 在 Project 窗口的 Models 文件夹（先建好）空白处，把 .fbx 文件直接拖进去。
  2. 或菜单【资源 Assets】→【导入新资源 Import New Asset】→ 选择文件。
  3. Unity 自动导入，右下角出现导入进度。
  4. 导入完成后，Project 里出现模型文件（显示为立体预览图标）。
  5. 把它从 Project 拖到场景里即可使用。
  6. 选中场景中的模型，检查 Mesh Filter（网格）与 Mesh Renderer（渲染）是否正常。
  7. 模型可能自带一个“默认材质”（灰白色），正式外观需上材质（第 37-38 课）。
💡
导入后有报错先看 Console：多数是材质引用或格式问题，按提示解决。

⚠常见错误与排查

⛔
错误：模型导入后是“问号/紫色”？
原因：Shader 或材质丢失
解决：模型自带的 Shader 可能与内置不同，重新创建 Standard 材质赋上即可。

★动手练习

课后小任务（做出来才算真的学会）

  • 下载一个免费 FBX 模型（或自建）导入项目
  • 把模型拖进场景并旋转查看全角度
  • 为模型创建并赋上一个简单材质
