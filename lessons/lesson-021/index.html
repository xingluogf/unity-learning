🚀课程导读

Unity 里万物皆对象（GameObject）。本课从哲学层面讲透“对象”概念，这是理解整个 Unity 的钥匙。

◆对象 = 空盒子 + 组件

把 GameObject 想象成一个空的工具箱。

  1. 【GameObject 游戏对象】本身只是一个“存在”的容器，本身没有外观、没有行为。
  2. 外观由组件提供：加【Mesh Filter + Mesh Renderer】就有形状能显示；加【Light】就能发光；加【AudioSource】就能发声。
  3. 行为由组件提供：加【Rigidbody】就会受重力；加自己写的【脚本】就有自定义逻辑。
  4. 所以：想让你创建的东西“是什么样、会做什么”，取决于你往盒子里放了哪些组件。
  5. 【空对象 Empty GameObject】 = 最纯粹的盒子，只带一个 Transform，常作为“管理器”“挂载点”使用。
  6. 层级里的每个对象，其实都是“空盒子+若干组件”的组合体。
💡
记住这句心法：Unity 编程 = 把合适的能力（组件）装配到对象上。

◆创建对象的几种方式

动手体验。

  1. 【方式1 菜单创建】：Hierarchy 右键 → 3D Object → Cube/Sphere 等，创建带默认组件的对象。
  2. 【方式2 空对象】：Hierarchy 右键 → Create Empty（或 Ctrl+Shift+N），得到只带 Transform 的空对象。
  3. 【方式3 代码创建】：脚本里用 new GameObject(“名字”) 创建，后续章节详讲。
  4. 【方式4 复制】：选中对象 Ctrl+D。
  5. 【方式5 预制体实例】：从 Project 把预制体拖进场景（第 32-34 课）。
  6. 现在创建 3 个空对象，分别命名为 Player、Enemy、Manager，看看 Hierarchy 里它们的区别。
💡
空对象常用于“空壳管理器”：放一个 Manager 空对象，挂上管理脚本，负责全局逻辑。

⚠常见错误与排查

⛔
错误：创建的对象在场景里看不见？
原因：对象没有可渲染的组件（如只有 Transform）
解决：空对象本就不显示，这是正常的；要显示需加 Mesh Renderer 等组件。
