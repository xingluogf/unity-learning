◆Android 环境配置

装好“工具链”。

  1. 【模块】Unity Hub 安装 Android Build Support（含 SDK/NDK/OpenJDK）。
  2. 【Player Settings】
  3. Company Name / Product Name。
  4. Bundle Identifier（唯一 ID，如 com.yourname.yourgame）。
  5. 【分辨率】默认方向（Portrait 竖屏/Landscape 横屏）按游戏设。
  6. 【图标】Adaptive Icon（安卓自适应图标）。
  7. 【纹理压缩】ASTC（第 266 课）。
  8. 【SDK 检查】Edit → Preferences → External Tools 确认路径。
  9. 【完成】环境“就绪”。
  10. 【注意】Bundle Identifier 全网唯一（上架用），提前定好。
💡
Android 准备 = 装模块 + Bundle ID + 方向 + 图标。四件套。

◆构建 APK 与真机测试

“装进手机”。

  1. 【构建】Build Settings → Android → Build 生成 .apk 文件。
  2. 【或】Build And Run（连手机直接装）。
  3. 【真机安装】把 APK 传到手机 → 点击安装（需允许“未知来源”）。
  4. 【测试】真机跑：性能（第 271 课）、触屏操作、方向、内存。
  5. 【设备兼容】高低端各测一台。
  6. 【日志】用 adb logcat 看真机日志（进阶）。
  7. 【AAB 上架】Google Play 用 .aab（Build Settings 选）。
  8. 【国内渠道】各应用商店有自己的要求（签名/加固，进阶）。
  9. 【完成】安卓版“上线”！
  10. 【注意】真机测试是必须的（编辑器≠真机）。
  11. 【推荐】开发期用“Development Build”方便看日志；发布用正式版。
✅
安卓发布 = 构建 APK → 传手机安装 → 真机测试。三步。

⚠常见错误与排查

⛔
错误：Build 失败（SDK 问题）？
原因：SDK/NDK 没配好
解决：重新安装 Android Build Support 模块；检查 External Tools 路径；看 Build 日志。
