🚀课程导读

“卡”是游戏杀手。本课学“先测后优”：用 Profiler 找到瓶颈再优化。

◆性能指标

看什么数据。

  1. 【帧率 FPS】每秒渲染帧数：60 流畅、30 及格、<30 卡。
  2. 【帧时间】每帧耗时（ms）：16.6ms=60fps、33.3ms=30fps。
  3. 【瓶颈】最耗时的环节（渲染/物理/脚本/GC）就是瓶颈。
  4. 【Draw Call】渲染调用数：越多越卡（第 224 课）。
  5. 【GC 分配】垃圾回收分配：每帧分配多→频繁 GC 卡顿。
  6. 【内存】占用多少、是否超限。
  7. 【目标】移动端 30-60fps、PC 60+、VR 90+。
  8. 【优化原则】先测后优、抓大头、用数据说话。
  9. 【注意】别凭感觉优化，数据驱动。
  10. 【完成】知道“看什么”。
  11. 【工具】Profiler 是最重要的性能工具。
💡
性能三指标：帧率（流畅度）、Draw Call（渲染）、GC（卡顿）。先测再优。

◆Profiler 使用

性能“体检仪”。

  1. 【打开】Window → Analysis → Profiler。
  2. 【录制】点 Record 录制当前场景性能数据。
  3. 【模块】
  4. CPU Usage：每帧各函数耗时（找热点）。
  5. Rendering：Draw Call、三角面数。
  6. Memory：内存占用。
  7. Physics：物理耗时。
  8. Scripts：脚本耗时。
  9. 【读法】播放时暂停，看 CPU 里哪一块占满（绿色渲染/紫色物理/蓝色脚本）。
  10. 【深入】点某个热点，看调用栈定位到具体函数/对象。
  11. 【Deep Profile】（进阶）逐函数剖析（慢但详细）。
  12. 【设备 Profile】（进阶）连真机看移动端真实性能。
  13. 【实战】运行你的游戏，找最耗时模块。
  14. 【完成】会用“体检仪”了！
  15. 【注意】Profiler 在编辑器会有点失真，真机更准。
✅
Profiler 读法：录 → 看 CPU 哪块满 → 点热点查栈 → 定位函数/对象 → 优化。

⚠常见错误与排查

⛔
错误：Profiler 数据看不懂？
原因：模块不熟
解决：先看 CPU Usage 主时间轴颜色分布；逐个展开模块；查调用栈。
