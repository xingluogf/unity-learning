🚀课程导读

同样的图片，用在不同地方（3D 贴图/UI/精灵）需要不同的导入类型。设置对了又快又清晰。

◆纹理类型选择

按用途选类型。

  1. 选中图片，Inspector 的【Texture Type】下拉：
  2. 【Default】：普通 3D 贴图（Albedo、法线等），绝大多数场景用它。
  3. 【Sprite (2D and UI)】：用于 2D 精灵与 UI 图片（第 202/149 课会用）。
  4. 【Normal Map】：法线贴图类型，用于凹凸效果。
  5. 【Editor GUI and Legacy GUI】：老式界面用，基本不用。
  6. 【Cursor / Cookie / Lightmap】等特殊用途，按需。
  7. 【Sprite Mode】在选 Sprite 类型时出现：Single（单张图）或 Multiple（多张拼图，切图用）。
💡
UI 图片必须选 Sprite 类型，否则 Canvas 无法显示！这是 UI 新手第一大坑。

◆压缩与 Mipmap

性能与画质的平衡。

  1. 【Generate Mip Maps 生成 Mipmap】：勾选后，Unity 为贴图生成一系列缩小版，远处物体用低清版，减少远处闪烁且提升性能。
  2. 代价：占用约 1.33 倍内存。3D 世界贴图建议开启；UI 图片建议关闭。
  3. 【Compression 压缩】：DXT/ASTC/ETC 等格式压缩，减小内存与包体。
  4. 质量优先选“高质量/原始”，性能优先选压缩格式；移动端必须用压缩格式。
  5. 【Max Size】：限制贴图最大分辨率（如 2048），超过会缩小，控制内存。
  6. 【Streaming Mipmap】：按需加载细节，进阶。
  7. 实战：把一张 4K 大图 Max Size 设为 1024 + 开启压缩，包体立刻变小，画质损失肉眼难辨。
⚠️
不要所有贴图都用 4K 最大尺寸，那是浪费内存；根据物体在画面中的大小合理设置。

⚠常见错误与排查

⛔
错误：贴图变模糊？
原因：Max Size 太小或压缩太狠
解决：把 Max Size 调大、压缩选高质量；UI 图片关闭 Mipmap。

★动手练习

课后小任务（做出来才算真的学会）

  • 把一张贴图分别设为 Default 和 Sprite 类型，观察图标变化
  • 开启/关闭 Generate Mip Maps，对比场景远处表现
