🚀课程导读

如果你做了 100 个相同的敌人，难道要一个个做？预制体就是“复制粘贴的模板”，改一处全部更新。

◆什么是预制体

预制体 = 一个“可复用的对象模板文件”。

  1. 预制体（Prefab）把“一个对象的完整配置”（组件、属性、子物体）保存成 Asset 文件。
  2. 场景中放 N 个“预制体实例”，就像用同一个模具印出 N 个成品。
  3. 好处 1：批量创建——拖一下就在场景生成一个，数量无限。
  4. 好处 2：统一修改——修改预制体本体，场景中所有实例同步更新。
  5. 好处 3：运行时动态生成——代码 Instantiate 一个预制体，就生成一个敌人/子弹/金币（第 76 课）。
  6. 预制体文件以 .prefab 后缀存在 Assets 里，场景文件只保存“引用”。
  7. 新手区分：场景里的对象是“实例”，Project 里的 .prefab 是“模板”。
💡
几乎所有会重复出现的东西（敌人、子弹、金币、道具）都该做成预制体。

◆预制体 vs 复制

为什么不用 Ctrl+D 复制。

  1. Ctrl+D 复制：得到的是“独立对象”，改一个不影响其他，批量修改要逐个改。
  2. 预制体实例：改模板全体更新，改某个实例可通过“覆盖(Override)”局部差异。
  3. 改模板：在 Project 双击预制体进入【预制体编辑模式】，修改后保存，全部实例更新。
  4. 实例化时想单独改某实例颜色：选中实例，在 Inspector 修改即可（出现蓝色“覆盖”标记）。
  5. 【变体】概念下一课讲；【嵌套预制体】（预制体里套预制体）进阶。
  6. 小结：要“批量且统一”用预制体，要“一次性的独立品”用复制。
✅
开发心法：凡是会重复出现的对象，先做成预制体，再摆进场景。

⚠常见错误与排查

⛔
错误：改了一个实例，其他实例没变？
原因：你改的是实例而非模板
解决：双击 Project 里的预制体进入编辑模式修改并保存，或把实例的修改通过 Inspector 顶部的 Overrides 应用到预制体。
