🚀课程导读

“脚下有没有地面”“前方有没有墙”“敌人看到我了吗”——2D 射线是逻辑“探针”。本课掌握。

◆Raycast2D 基础

从一点射“探针”。

  1. 【API】Physics2D.Raycast(起点, 方向, 距离, LayerMask)；
  2. 返回 RaycastHit2D。
  3. 【示例】向下检测地面：
  4. RaycastHit2D hit = Physics2D.Raycast(transform.position, Vector2.down, 0.6f, groundLayer);
  5. if (hit.collider != null) { /* 有地面 */ }
  6. 【判断】hit.collider != null 表示射中了东西。
  7. 【方向】Vector2.down/up/left/right 或自定义。
  8. 【距离】射线长度（检测范围）。
  9. 【LayerMask】过滤只检测某层（地面层/敌人层），避免误判。
  10. 【调试】Debug.DrawRay(起点, 方向*距离, Color.red); 场景里可视化看射线。
  11. 【注意】2D 射线用 Physics2D，别和 3D Physics.Raycast 混用。
  12. 【性能】每帧几次射线没问题，批量上百次要注意（用批处理）。
💡
2D 射线 = Physics2D.Raycast + 判断 hit.collider。一个“探针”搞掂所有检测。

◆典型应用

地面、悬崖、视野。

  1. 【地面检测替代方案】用射线替代 OverlapCircle（第 205 课）做 grounded：
  2. bool grounded = Physics2D.Raycast(transform.position, Vector2.down, 0.1f, groundLayer).collider != null;
  3. 【悬崖检测】在角色前方地面斜下射一条射线，射不中就“前方是悬崖”（敌人 AI 转向用）。
  4. 【墙体检测】向前射短射线，撞墙停止移动。
  5. 【敌人视野】敌人向前射较长射线 + 视野范围：
  6. RaycastHit2D hit = Physics2D.Raycast(transform.position, facing, sightDist, playerLayer);
  7. if (hit.collider != null) /* 发现玩家，进入追击 */
  8. 【层设置】给玩家/敌人/地面分 Layer（第 88 课），用 LayerMask 精确过滤。
  9. 【LayerMask 写法】int groundLayer = 1 << LayerMask.NameToLayer("Ground");
  10. 【方向翻转】敌人 flipX 后，射线方向也要翻转（用 transform.right 或本地方向）。
  11. 【注意】射线从“原点”出发别穿过自己碰撞体（用 offset 或 LayerMask 过滤自己）。
  12. 【实战】做敌人“悬崖边转身”AI。
  13. 【完成】你的 2D 逻辑“有眼睛”了！
✅
射线三剑客：向下验地、向前验墙、向敌人验视野。2D 逻辑全靠它。

⚠常见错误与排查

⛔
错误：射线永远检测不到？
原因：LayerMask 过滤掉了、或起点在自己碰撞体内
解决：确认目标在对应 Layer 且 Mask 包含它；射线起点加偏移避开自身。
