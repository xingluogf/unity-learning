🚀课程导读

2D 游戏里的角色、背景、道具都是 Sprite。本课把精灵从导入到使用讲透。

◆导入精灵

图片变成“游戏素材”。

  1. 【导入】把 .png/.jpg 拖进 Project 的 Sprites 文件夹。
  2. 【设为精灵】选中图片 → Inspector → Texture Type 选【Sprite (2D and UI)】→ Apply。
  3. 【PPU（Pixels Per Unit）】每单位包含多少像素：PPU=100 → 100 像素的图=1 单位大小。
  4. 【调 PPU】想让角色大一点就调小 PPU（如 64）；统一风格建议全项目同一 PPU。
  5. 【Filter Mode】Bilinear 平滑 / Point 像素风（复古游戏用 Point）。
  6. 【Compression】压缩：UI 用 None、精灵用压缩（可选）。
  7. 【多图】图集 Sprite Mode=Multiple（第 203 课切分多张）。
  8. 【完成】图片成为可用精灵。
  9. 【注意】透明图用 PNG（带 Alpha）；JPG 无透明。
  10. 【资源检查】确认导入无误后再使用。
💡
精灵导入三设置：Texture Type=Sprite、PPU 定大小、Filter Mode 定风格。

◆SpriteRenderer 组件

把精灵放进场景。

  1. 【创建】把精灵图直接拖进场景（或建空对象+Add Component → Sprite Renderer）。
  2. 【组件】SpriteRenderer：Sprite（精灵图）、Color（染色）、Flip（翻转）、Sorting Layer/Order（层级）。
  3. 【Color 染色】白色方块技巧：给精灵染色（幽灵半透明、变红受伤提示）。
  4. 【Flip】Flip X/Y 水平/垂直翻转（角色朝左朝右）。
  5. 【Sorting Layer 排序层】控制“谁盖在谁上面”：
  6. Edit → Project Settings → Tags and Layers → Sorting Layers 添加层（Background、Default、Player、Foreground）。
  7. 【Order in Layer】同层内的排序（数字大的在上）。
  8. 【优先级】背景层在最底、角色在中间、UI 特效在最顶。
  9. 【换图】代码：spriteRenderer.sprite = newSprite;
  10. 【颜色】spriteRenderer.color = new Color(1,1,1,0.5f); // 半透明
  11. 【注意】2D 物体的前后关系看 Sorting，不是 Z 坐标（相机正交）。
  12. 【完成】精灵能在场景正确显示了！
✅
SpriteRenderer 三兄弟：Sprite 图、Sorting 层级、Flip 翻转。2D 显示全靠它。

⚠常见错误与排查

⛔
错误：精灵图拖不进场景/不显示？
原因：Texture Type 不是 Sprite
解决：选中图片设 Texture Type=Sprite 并 Apply。
