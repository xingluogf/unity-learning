🚀课程导读

场景（Scene）是游戏的一个“关卡/界面”。本课教你管理多个场景，让项目井井有条。

◆场景基础操作

保存、新建、切换。

  1. 【保存场景】：Ctrl+S 快速保存当前场景；或菜单【文件 File】→【保存场景】。
  2. 【新建场景】：菜单【文件】→【新建场景 New Scene】→ 选择模板（如空场景 Basic (Built-in)）→ 创建。
  3. 【切换场景】：在 Project 窗口双击任意 .unity 场景文件，即可切换到该场景。
  4. 【另存为】：菜单【文件】→【另存场景为 Save Scene As】可把当前场景另存为新文件（如场景 2、场景 3）。
  5. 【同时打开多个场景】：（较新版本）Window→Scene Management 可管理多场景叠加，新手先用单场景即可。
  6. 修改场景后未保存，Hierarchy 标签和场景文件旁会有“星号/圆点”提示，记得保存。
💡
养成习惯：每完成一个阶段就 Ctrl+S，避免白干。按 Ctrl+Z 也能撤销大部分误操作。

◆场景组织建议

场景多了不混乱的诀窍。

  1. 每个场景一个用途：如 MainMenu（主菜单）、Level1（第一关）、Level2（第二关）。
  2. 所有场景放进 Assets/Scenes 文件夹统一管理。
  3. 场景命名全英文小写 + 数字（如 level_01），别用中文。
  4. 【构建设置添加场景】：（第 281 课详讲）菜单 File→Build Settings，把用到的场景拖进列表，游戏运行时才能切换。
  5. 场景间数据传递（如分数）用后续的存档/单例方案解决（第 234/238 课）。
⚠️
只建了场景但没加进 Build Settings，发布后切不了场景！这是新手常见坑。

⚠常见错误与排查

⛔
错误：切到其他场景后，之前的场景内容不见了？
原因：不同场景是不同文件
解决：双击之前保存的 .unity 文件即可切回；确保修改后都保存过。
