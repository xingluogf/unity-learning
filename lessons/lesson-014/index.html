🚀课程导读

Inspector 是“属性面板”，选中对象后在这里看它的“体检报告”并改造它。组件（Component）概念是本课核心。

◆认识 Inspector 与组件

对象 = 空壳 + 一堆组件。

  1. 在 Hierarchy 选中 Cube，右侧 Inspector 显示该对象的所有组件。
  2. 最顶部是【Transform】组件：任何对象都有，包含 Position（位置）、Rotation（旋转）、Scale（缩放）。
  3. 下面常见组件：【Mesh Filter】（网格，定义形状）、【Mesh Renderer】（网格渲染，负责显示）、【Box Collider】（盒形碰撞体，负责“被撞”）。
  4. 每个组件顶部有组件名、小问号（帮助）、右侧三个点（菜单），底部是折叠/展开。
  5. 勾选组件名左边的【√】可以临时禁用该组件（灰色显示，不再生效），再点一下恢复。
  6. 点组件名右侧的三个点 →【Remove Component】可删除该组件。
  7. 点【Add Component】按钮可搜索并添加新组件，如 Rigidbody、Light、AudioSource 等。
  8. 修改任意数值（如 Scale）后，场景里的物体立即变化——所见即所得。
💡
组件右上角小齿轮/三点菜单里还有【Reset（重置）】可以把组件属性恢复默认，调试乱套时用它。

◆常用属性操作技巧

几个提升效率的小技巧。

  1. 鼠标点住数值左右拖动可快速调整（拖拽调数）。
  2. 按住 Ctrl 再拖动数值会以更小步长微调；按住 Shift 以更大步长快调。
  3. 右键点击数值标签 → 可输入精确值 / 复制 / 粘贴，多个物体同步粘贴属性。
  4. 把 Project 里的资源（如材质）直接拖到 Inspector 属性槽中即可赋值。
  5. 颜色属性：点色块弹出拾色器，也可直接输入十六进制色值（如 #FF0000 红色）。
  6. 想同时看多个对象属性：在 Hierarchy 按住 Ctrl 多选，Inspector 会显示共有的组件。
💡
右键属性标签选择“Copy Component”/“Paste Component”可把一个物体的组件完整复制到另一个物体，做同款物体超快。

⚠常见错误与排查

⛔
错误：Inspector 里没有组件显示？
原因：未选中任何对象
解决：先在 Hierarchy 中点击选中一个对象。

★动手练习

课后小任务（做出来才算真的学会）

  • 选中 Cube，分别修改它的位置/旋转/缩放
  • 禁用并恢复 Mesh Renderer，观察物体消失又出现
  • 添加 Rigidbody 组件再删除它
