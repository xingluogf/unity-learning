🚀课程导读

在电脑上打开你的项目文件夹，会看到一堆东西。别慌，本课把它们一个个讲明白。学会管理项目文件，是专业开发的第一步。

◆项目文件夹里的内容

先用文件资源管理器打开项目所在目录（即你创建项目时选的 Location 下的项目名文件夹）。

  1. 【Assets】文件夹：最核心！你的所有资源（模型、贴图、脚本、场景、预制体）都放这里，几乎所有操作都在它内部完成。
  2. 【Packages】文件夹：Unity 管理插件包（Package）的地方，一般不用手动动它。
  3. 【ProjectSettings】文件夹：项目设置，如画质、输入、平台设置都存这里，自动生成。
  4. 【Library】文件夹：Unity 的“缓存库”，保存导入缓存、编译结果，可以随时删除（下次打开会自动重建），但不要手动改它。
  5. 【Temp】文件夹：临时文件，同样自动生成可删除。
  6. 【Logs】文件夹：运行日志，排查崩溃时有用。
  7. 【.gitignore】等隐藏文件：配合 Git 版本管理使用（第 278 课讲）。
  8. 总结：你 99% 的时间都在 Assets 文件夹里工作。
⛔
绝对不要手动删除或重命名 Assets 里的文件！在 Unity 里删资源应选中后按 Delete 键（会同步处理引用）。直接改文件名会让场景/脚本引用断裂。

◆Assets 内部建议的分目录习惯

从一开始就养成好习惯，项目大起来不混乱。

  1. 在 Project 窗口里右键 →【创建 Create】→【文件夹 Folder】，创建一个叫 Scenes 的文件夹，用来放场景文件。
  2. 再创建 Scripts 文件夹：放 C# 脚本。
  3. 再创建 Materials（材质）、Textures（贴图）、Models（模型）、Audio（音频）、Prefabs（预制体）、UI 等文件夹。
  4. 规则：一个资源类型一个文件夹，名称用英文小写复数，层次别超过 3 层。
  5. 把默认场景 SampleScene 拖到 Scenes 文件夹里（直接拖动即可，Unity 会自动更新引用）。
  6. 这样你的项目从一开始就井井有条。
💡
Resources 文件夹比较特殊（代码可按名加载），新手阶段先不用管，后面讲到再提。

⚠常见错误与排查

⛔
错误：不小心在电脑上删了 Assets 里的文件，Unity 报一堆错？
原因：外部删除导致引用断裂
解决：如果还没删，赶紧在系统回收站还原；已删且无备份，只能重建引用。所以务必在 Unity 内部管理文件！
