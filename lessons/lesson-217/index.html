🚀课程导读

关卡一堆方块手摆太慢——Tilemap 用“笔刷”画地形，快 10 倍。本课掌握。

◆创建 Tilemap

画布 + 笔刷。

  1. 【创建】Hierarchy 右键 → 2D Object → Tilemap → Rectangular，生成 Grid + Tilemap 对象。
  2. 【Grid】格子容器；【Tilemap】画布（可多层：Ground、Decoration）。
  3. 【准备瓦片】准备瓦片精灵图（如 16x16 的地块）。
  4. 【打开窗口】Window → 2D → Tile Palette 打开瓦片面板。
  5. 【建 Palette】Create New Palette，命名 Ground，保存。
  6. 【导入瓦片】把精灵图拖进 Palette 窗口（需 Texture Type=Sprite、PPU 匹配，第 202 课）。
  7. 【自动切片】若图是多帧，选 Sprite Mode=Multiple 用 Sprite Editor 切分（第 203 课）。
  8. 【完成】Palette 里有瓦片可刷了！
💡
Tilemap = 网格 + 笔刷：Palette 装瓦片，刷子画地形。搭关如“画图”。

◆绘制与碰撞

画出关卡并让它“可踩”。

  1. 【绘制】选 Palette 里的瓦片（选单个或框选多个），在 Scene 里点击/拖动画地形。
  2. 【橡皮】Palette 工具选“擦除”工具抹掉。
  3. 【填充】填充工具刷一大片。
  4. 【多层】创建第二个 Tilemap（如 Decoration）画装饰，Sorting 在 Ground 上面。
  5. 【碰撞】给 Tilemap 加【Tilemap Collider 2D】组件：瓦片自动生成碰撞。
  6. 【优化】再加【Composite Collider 2D】+ 勾 Use By Composite：把相邻瓦片合并成一个碰撞体（性能更好、角色不卡缝）。
  7. 【层级】确认 Tilemap 的 Sorting Order 在背景之上、角色之下。
  8. 【测试】画好地面，角色能踩上去（碰撞生效）。
  9. 【注意】Composite 合并后碰撞是一整块，斜坡/台阶要单独处理。
  10. 【进阶】Rule Tile 规则瓦片自动适配相邻（自动地形）。
  11. 【完成】关卡“画”出来了！
✅
Tilemap 三件套：Palette 装瓦片、笔刷画地形、TilemapCollider2D 做碰撞。效率翻倍。

⚠常见错误与排查

⛔
错误：刷不上瓦片？
原因：精灵没切片或 Palette 未建
解决：确认瓦片精灵 Type=Sprite；Palette 已创建并拖入瓦片；选中瓦片工具再画。
