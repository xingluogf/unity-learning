🚀课程导读

选中 Project 里的模型文件，Inspector 会出现“导入设置”面板。设置得当，模型才能正确显示与动画。

◆模型 Model 页签

核心几何设置。

  1. 在 Project 中选中 .fbx 文件，Inspector 顶部出现【模型 Model】【动画 Rig】【动画 Animation】三个页签。
  2. 先看【模型】页：【Scale Factor 缩放因子】默认 1，若模型过大/过小，调它（如 0.01 让 100 倍大的模型变小）。
  3. 【Convert Units】：把单位从厘米/英寸转成米，一般保持勾选。
  4. 【Read/Write Enabled】：勾选后可运行时读取网格数据（多数情况不用）。
  5. 【Mesh Compression】：网格压缩，可减小包体，非性能敏感时建议开启（Off/Low/High）。
  6. 【Generate Colliders】：勾选则自动生成碰撞体（模型能“被撞”），按需勾选。
  7. 点右下角【Apply 应用】保存设置。
💡
改完任何设置必须点【Apply】才生效，很多新手忘记这步。

◆动画页签设置

模型带动画时在这设置。

  1. 【Rig 页签】：Animation Type 选 Humanoid（人形，可用人形动画）或 Generic（通用，适合非人形）；None 则禁用动画。
  2. 【Animation Type】选 Humanoid 后，下方出现【Avatar Definition】等，保持默认即可。
  3. 【Animation 页签】：列出模型内包含的所有动画片段（Animation Clip）。
  4. 可勾选【Loop Time 循环】让动画循环播放（走路、待机）。
  5. 可把动画片段“剥离”成独立 .anim 文件方便管理（编辑 Animation 页签→右键动画→保存为外部文件）。
  6. 点击【Apply】应用全部设置。
  7. 完成设置后，把模型拖入场景，在动画窗口即可预览动画（第 9 章详讲）。
💡
动画相关的高级设置在动画章节（第 9 章）会有更详细讲解，这里先会用导入选项。

⚠常见错误与排查

⛔
错误：模型太大/太小？
原因：建模时单位不同
解决：调整 Import Settings 的 Scale Factor，直到在场景里看起来合适。

★动手练习

课后小任务（做出来才算真的学会）

  • 导入一个模型，把 Scale Factor 调整为 0.5 看效果
  • 查看该模型的 Rig 页签动画类型
  • 给带动画的模型勾选 Loop Time
