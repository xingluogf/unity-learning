◆全局音频管理器

一站式声音中心。

  1. 创建空对象 AudioManager，挂单例脚本（第 86 课 + 172 课 DontDestroyOnLoad）：
  2. public class AudioManager : MonoBehaviour {
  3. public static AudioManager Instance;
  4. public AudioSource bgmSource;
  5. public AudioSource sfxSource;
  6. void Awake() {
  7. if (Instance != null) { Destroy(gameObject); return; }
  8. Instance = this;
  9. DontDestroyOnLoad(gameObject);
  10. }
  11. public void PlayBGM(AudioClip clip) { bgmSource.clip = clip; bgmSource.Play(); }
  12. public void PlaySFX(AudioClip clip) { sfxSource.PlayOneShot(clip); }
  13. public void PlaySFX(AudioClip clip, float volume) { sfxSource.PlayOneShot(clip, volume); }
  14. public void SetBGMVolume(float v) { bgmSource.volume = v; }
  15. }
  16. 【两个 AudioSource】bgmSource（Loop、低优先）、sfxSource（一次性、高优先）。
  17. 【PlayOneShot】同一个 Source 可叠加多个音效（不打断），适合密集音效。
  18. 【调用】AudioManager.Instance.PlaySFX(hitSound); 任何脚本都能用。
  19. 【注意】跨场景时引用要用单例，别存当前场景的引用。
  20. 【完整】BGM/SFX 全局可调、跨场景不丢。
💡
AudioManager = 单例 + DontDestroyOnLoad + 双 AudioSource（BGM+SFX）。

◆整合混音器与音量

接入 Mixer 与设置。

  1. 给 AudioManager 的两个 Source 的 Output 分别路由到 Music 组与 SFX 组（第 176 课）。
  2. 接入设置面板：音量滑块 → mixer.SetFloat（第 177 课）。
  3. 【音效绑定】给游戏各动作加音效：
  4. 跳跃 → PlaySFX(jumpSound)；金币 → PlaySFX(coinSound)；攻击 → PlaySFX(attackSound)。
  5. 【3D 音效】角色脚步/环境音用 3D Source（第 175 课）。
  6. 【音乐切换】进入新场景时（或场景事件）PlayBGM(新音乐)。
  7. 【淡入淡出】切 BGM 时协程渐变音量。
  8. 【随机】SFX 用随机 Pitch（第 173 课）。
  9. 【完整测试】BGM 循环、切场景不断、SFX 各动作发声、音量面板生效、静音生效。
  10. 【优化】检查 Console 无 AudioListener 重复、无缺失引用。
  11. 【收尾】保存场景，音频系统毕业！
💡
一套可复用的 AudioManager 让未来所有游戏“开箱即响”。

⚠常见错误与排查

⛔
错误：切场景后 AudioManager 重复？
原因：单例检查没写对
解决：Awake 里 if(Instance!=null) Destroy(gameObject) return; 再赋值 Instance。
