🚀课程导读

有的游戏角色移动全靠代码，有的靠“动画自带位移”（跑动画会带着角色前进）。后者就是 Root Motion。

◆什么是 Root Motion

动画“拖着人走”。

  1. 【普通方式】动画在原地播放，位移由代码控制（transform.position += ...）。
  2. 【Root Motion】动画片段本身记录了“根骨（Root）”的位移，播放时带动整个角色移动。
  3. 【效果】跑步动画自带前进，播放时角色自动向前跑。
  4. 【优点】动作与位移完美同步（尤其跳跃、翻滚这类“动作=位移”的）。
  5. 【缺点】位移速度由动画决定，代码控制自由度降低。
  6. 【开关】Animator 组件勾选/取消【Apply Root Motion】。
  7. 【注意】Root Motion 需要动画片段里有根骨骼运动数据（烘焙的位移）。
💡
简单判断：走路/跑步若动画自带“身体前倾+位移”，就用 Root Motion；纯原地动画则用代码移动。

◆配置与选择

何时用、怎么用。

  1. 【启用】角色 Animator 勾选 Apply Root Motion，播放自带位移的动画，角色自动移动。
  2. 【代码移动二选一】用 Root Motion 后，别再用代码 transform 位移（会叠加冲突）。
  3. 【用 Root Motion 的方式】输入控制“动画状态”（走路/跑步），位移交给动画。
  4. 【混合方式】Root Motion 提供位移 + 代码只做转向/方向控制。
  5. 【关卡动画】过场动画/机关动画用 Root Motion 精确位移。
  6. 【禁用场景】走格子、精确操控（如小游戏）用代码位移更可控，取消 Apply Root Motion。
  7. 【根运动设置】动画片段的 Root Transform Rotation/Position 属性（第 129 课）控制根运动行为。
  8. 【验证】勾选后播放，观察角色是否随动画移动。
✅
判断标准：动作自带位移（跑跳翻滚）→ Root Motion；动作原地（待机、攻击）→ 代码位移。

⚠常见错误与排查

⛔
错误：勾了 Root Motion 但角色不动？
原因：动画片段没烘焙根位移
解决：检查动画片段是否有根运动数据；或改用代码位移并取消 Root Motion。
