渲染是 3D 游戏最大开销。本课把 Draw Call 与光影成本降下来。

◆合批技术

让 GPU 一次画一批。

  1. 【静态合批】静态物体（勾 Static）同材质自动合并：一次渲染调用。
  2. 【条件】同材质 + 同 Shader + 静态。
  3. 【动态合批】小物体（顶点少）自动合批（Unity 自动，有条件：顶点数限制）。
  4. 【SRP Batcher】URP 的合批器：同 Shader 变体材质批量渲染（默认开）。
  5. 【GPU Instancing】大量同模型同材质：实例化绘制（草、树）。
  6. 【图集】UI/精灵合批（第 203 课）。
  7. 【查看】Frame Debugger（Window → Analysis）看 Draw Call 与合批情况。
  8. 【优化动作】
  9. 统一材质（少换材质）。
  10. 同材质物体勾 Static。
  11. 用图集/共享贴图。
  12. 【目标】手游 Draw Call < 100-200。
  13. 【测试】Profiler/Frame Debugger 对比合批前后。
  14. 【完成】Draw Call “打下来了”！
💡
合批四法：静态合批、动态合批、SRP Batcher、GPU Instancing。按场景选。

◆光影优化

少算光。

  1. 【烘焙】静态场景光影烘焙（第 192 课）：运行零光照计算。
  2. 【灯光数量】实时灯少用（URP 限制 + 性能）。
  3. 【阴影】少开/近距阴影（第 192 课 Shadow Distance）。
  4. 【反射探针】一个反射探针服务一片区域（别每物一个）。
  5. 【后处理】Bloom 等适量（第 195 课）。
  6. 【Shader】用 URP 轻量 Shader；少用复杂 Shader。
  7. 【材质】减少多 Pass/透明材质。
  8. 【LOD】远处低模（第 245 课）。
  9. 【综合】“烘焙 + 少灯 + 短阴影”是 3D 场景标配。
  10. 【测试】逐项开关对比帧率。
  11. 【完成】光影成本“可控”。
  12. 【推荐】静态全烘焙、动态只开必要的灯。
  13. 【说明】URP 对光照数量有严格限制（Forward 每物体最多 8 实时灯）。
✅
光影优化口诀：静态烘焙、实时灯少、阴影短、后处理轻。四句够用。

⚠常见错误与排查

⛔
错误：合批没生效？
原因：材质不同或没勾 Static
解决：统一材质；静态物体勾 Static；用 Frame Debugger 确认合批。
