◆LOD 落地

给大场景装 LOD。

  1. 【准备】场景里的大物体（建筑、树、山体）需要多精度模型（美术提供或商店）。
  2. 【添加】选中物体 → Add Component → LOD Group。
  3. 【配置】LOD 0（最高模）、LOD 1（中模）、LOD 2（低模）、Culled。
  4. 【拖模型】每级把对应 Renderer 拖入。
  5. 【距离】默认比例（如 0.6/0.3/0.1），按场景大小调整。
  6. 【预览】Scene 视图 Camera 模式看各级切换效果。
  7. 【低模来源】可用 Blender 减面/商店 LOD 包；或手动简化（进阶）。
  8. 【静态物体】LOD 配合 Static 效果更好。
  9. 【验证】Profiler 看三角面数（Triangles）明显下降。
  10. 【完成】LOD“落地”！
  11. 【注意】移动端 LOD 更要积极（低模切换更早）。
💡
LOD 落地 = LOD Group 组件 + 三级模型 + 距离配置。三角面数立降。

◆遮挡剔除落地

让看不见的不渲染。

  1. 【准备】把场景静态物体（墙、建筑、地形）勾 Static（含 Occluder）。
  2. 【窗口】Window → Rendering → Occlusion Culling。
  3. 【Bake】点 Bake（等进度条完成）。
  4. 【检查】Scene 视图选 Occlusion Culling 模式：
  5. 蓝色=遮挡体、绿色=被遮挡物、黄色=动态物。
  6. 【验证】播放后移动相机，用 Profiler/Stats 看 Draw Call 变化。
  7. 【常见问题】烘焙后闪烁 → 改场景重新 Bake。
  8. 【动态物】角色/敌人是动态物：被静态遮挡剔除（也受益）。
  9. 【性能】遮挡烘焙有内存开销：场景大分区域烘焙（进阶）。
  10. 【完成】遮挡剔除“落地”！
  11. 【测试】站在墙后，看墙后 Draw Call 是否为 0。
  12. 【注意】只用实心大物体做遮挡体（墙），别用透明/小物。
✅
遮挡剔除落地 = 静态勾选 + Bake + 验证。室内场景 Draw Call 立降。

⚠常见错误与排查

⛔
错误：遮挡烘焙后画面闪烁？
原因：烘焙数据过期或遮挡体设置错
解决：改场景后重新 Bake；用实心大物体做遮挡体；检查 Static 勾选。
