🚀课程导读

很多人第一次打开 Unity 会被复杂的界面吓到。别担心，这一课我们先不谈操作，只用最通俗的话讲清楚：Unity 到底是什么、它能做什么、你为什么学它。心态摆正了，后面 299 课会非常顺利。

◆什么是游戏引擎

游戏引擎 = 做游戏的全套工具箱，它帮我们处理画面渲染、物理碰撞、声音播放、输入响应等最底层的工作，我们只需专注“编游戏”。

  1. 想象你要盖一栋房子：游戏引擎就是已经帮你做好“地基、水电、钢筋”的施工队，你只需要往里面添砖加瓦（摆放模型、写逻辑）。
  2. 没有引擎的话，你连“屏幕上显示一个方块”都要自己写几千行底层代码；有了引擎，拖一个方块进去就行。
  3. Unity 是目前全球使用人数最多的游戏引擎之一，手机游戏（王者荣耀、原神这类团队作品也有 Unity 项目）、电脑游戏、网页游戏、VR 应用都能用它做。
  4. Unity 用 C# 语言写游戏逻辑，用“场景”组织内容，用“组件”给物体添加能力——这三个概念后面会反复用到，先有个印象即可。
💡
不需要记住任何术语，只要记住：Unity 让你用“搭积木 + 写代码”的方式做游戏。

◆Unity 能做什么

先建立目标感，看到成品才有动力。

  1. 2D 游戏：横版跑酷、跳跃闯关、塔防、卡牌、解谜，都是 Unity 的强项。
  2. 3D 游戏：第一人称射击、第三人称动作、开放世界、模拟经营，统统可以。
  3. 其他领域：汽车/建筑可视化、VR 虚拟现实、AR 增强现实、数字孪生、影视动画，Unity 也大量使用。
  4. 学完这套 300 课，你将能从零做出可运行的 2D 与 3D 小游戏，并具备继续深入任何方向的底子。
✅
不要贪多，先把“做出一个小游戏”作为目标，成就感是最好的老师。

◆你需要准备什么

看看硬件和软件要求，提前避坑。

  1. 一台电脑：Windows 10/11 或 macOS 都可以。内存建议 8GB 以上（越大越流畅），硬盘预留 20GB 以上空间。
  2. 集成显卡也能跑入门项目，但如果做 3D 复杂场景会卡，独立显卡（GTX 1050 以上级别）体验更好。
  3. 下载 Unity 完全免费（个人版）。需要联网下载安装包与后续资源。
  4. 准备一个邮箱，用来注册 Unity 账号（下一课教）。
  5. 浏览器推荐 Chrome 或 Edge，后面会频繁用网页版教程与资源。

⚠常见错误与排查

⛔
错误：我的电脑配置很低，能学吗？
原因：低配置跑大项目确实吃力
解决：可以学。先做 2D 项目和简单 3D 场景，把画质等级调低（Edit→Project Settings→Quality 选 Low），避免打开大资源即可。
