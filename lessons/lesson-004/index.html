下载安装 Unity Hub（管理器）

🚀课程导读

Unity Hub 就像手机的应用商店：它负责下载/管理多个 Unity 引擎版本、创建项目、管理你的项目列表。安装它只需几分钟，跟着步骤走。

◆下载 Unity Hub

先拿到安装包。

  1. 打开浏览器访问 unity.cn。
  2. 把鼠标移到页面顶部导航栏的【下载】菜单（或在页面中部找到“下载 Unity”大按钮）并点击。
  3. 页面会显示【Unity Hub】下载卡片，选择对应你电脑系统的版本：Windows 系统点 Windows 版（.exe 文件）。
  4. 点击下载，浏览器开始下载安装包（约 100MB 左右），等待下载完成。
💡
如果你在国外官网 unity.com 下载，找 Download → Unity Hub → 选 Windows 即可。

◆安装 Unity Hub

双击安装包，一路下一步。

  1. 打开下载文件夹（通常是 C:\Users\你的用户名\Downloads），找到刚下载的文件（文件名类似 UnityHubSetup.exe）。
  2. 双击该文件，系统可能弹出“是否允许此应用更改设备？”的安全提示，点击【是】。
  3. 进入安装向导，默认语言选“中文”（或英文），点击【下一步 / Next】。
  4. 选择安装位置：默认即可（建议 C 盘或空间充足的盘），点击【安装 / Install】。
  5. 等待进度条走完（约 1-3 分钟），勾选“立即运行 Unity Hub”，点击【完成 / Finish】。
  6. Unity Hub 窗口弹出，首次打开会有欢迎引导，直接关闭引导即可。
⚠️
如果安装卡在“下载中”很久，检查网络；国内网络一般没问题，若失败可重试一次。

◆登录 Unity Hub

把 Hub 与你的账号绑定。

  1. Unity Hub 左上角有一个人形图标（头像），点击它，弹出登录面板。
  2. 点击【登录 / Sign in】。
  3. 浏览器会打开登录页面，输入第 3 课注册的邮箱和密码，点击登录。
  4. 登录成功后会跳转回 Hub，右上角显示你的头像，说明已绑定账号。
  5. 顺便看一眼左下角【设置】图标 →【许可证】页面：应该已显示“个人版 Personal”或可免费激活的许可证，这正是我们要的（下一课详解）。
💡
账号登录失败时检查：邮箱是否拼错、密码是否记错、网络是否正常。

⚠常见错误与排查

⛔
错误：安装到最后提示“需要管理员权限”？
原因：安装程序需要写入系统目录
解决：右键安装包，选择【以管理员身份运行】即可。
⛔
错误：Hub 打开后是英文界面？
原因：语言设置默认英文
解决：点击左下角齿轮【设置】→【General】→ 将 Language 改为“中文”，重启 Hub 生效。

★动手练习

  • 打开【设置】确认许可证页面显示 Personal 个人版
