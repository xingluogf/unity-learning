◆什么是方法

一段“有名字的指令块”。

  1. 方法（Method/函数）把一段逻辑封装起来，起个名字，需要时“调用”它。
  2. 好处：代码复用（一处定义、多处调用）、逻辑清晰、易维护。
  3. Unity 里 Start()、Update() 就是系统自动调用的方法；我们也可以自己定义。
  4. 自己定义方法的语法：访问修饰符 返回类型 方法名(参数列表) { 方法体 }
  5. 例：void SayHello() { Debug.Log("你好"); }
  6. 【调用】：SayHello(); 直接写方法名加括号。
  7. 调用时，程序跳进方法体执行，执行完回到调用处继续。
  8. 方法名用大驼峰：StartGame、TakeDamage。
💡
方法命名要“动词”化（做什么）：MovePlayer、AttackEnemy。

◆定义与调用实战

写一个方法并调用。

  1. 新建脚本 MethodDemo，在类里（Start 外面）定义一个方法：
  2. void ShowMessage() { Debug.Log("这是自定义方法输出"); }
  3. 在 Start 里调用三次：ShowMessage(); ShowMessage(); ShowMessage();
  4. 播放：输出三行日志。
  5. 再定义一个带“功能”的方法：void AddScore() { score += 10; Debug.Log("分数：" + score); }
  6. 声明字段 int score = 0; 在 Start 里调用 AddScore() 两次。
  7. 体会：方法把“加 10 分并显示”打包成一个动作。
  8. 方法里可以调用其他方法：void A() { B(); } void B() { Debug.Log("B"); }
✅
凡是“会重复出现的逻辑”都提成方法：一处修改，处处生效。

⚠常见错误与排查

⛔
错误：方法没被调用就“不执行”？
原因：方法定义后不会自动运行
解决：方法需要被调用才执行：在 Start/Update 或其他方法里写上 方法名();
