🚀课程导读

很多 Unity 高级功能（新版输入系统、后处理、Tilemap 等）都需要先“安装包”。本课教你怎么装。

◆认识 Package Manager

Unity 的“应用商店”（官方包）。

  1. 打开：菜单【窗口 Window】→【包管理器 Package Manager】。
  2. 左侧是包列表，右上角【+】可添加包。
  3. 顶部下拉可切换来源：【Unity Registry】（官方注册表）【My Assets】（我的资源）【Built-in】（内置包）。
  4. 【Packages 项目自带的包】区域列出当前项目已安装的所有包（如 UI、Physics、Timeline 等）。
  5. 官方包 = Unity 把某些功能拆成独立模块，按需安装，减小引擎体积。
💡
打开包管理器时若网络慢，左侧列表可能加载久，稍等即可。

◆安装与卸载包

实操一个例子：安装 Tilemap（2D 瓦片地图）。

  1. 在 Package Manager 左上角下拉选【Unity Registry】。
  2. 在搜索框输入“Tilemap”。
  3. 在结果中点击【Tilemap】，右侧显示详情与版本。
  4. 点右下角【安装 Install】，等待进度完成。
  5. 安装成功后，Project 的 Packages 区域出现 com.unity.2d.tilemap 包。
  6. 以后右键创建时就会多出 Tilemap 相关选项（第 207 课用）。
  7. 【卸载】：选中包，点【移除 Remove】（内置包不可移除）。
  8. 【更新】：包有新版本时，右侧会显示【Update】按钮。
  9. 【官方常用包】：Input System（新版输入）、Post Processing（后处理）、Cinemachine（智能相机）、TextMeshPro（文字）。
💡
安装新包后若项目报错，多半是版本冲突，查看 Console 并升级/降级包版本解决。

⚠常见错误与排查

⛔
错误：安装包一直转圈/失败？
原因：网络问题或源不可达
解决：检查网络；切换来源；或稍后重试。中国区用户可尝试使用 Unity 中国版镜像源。
