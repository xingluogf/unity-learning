🚀课程导读

Asset Store 是 Unity 官方资源市场，海量免费模型/贴图/脚本/插件。学会用它，开发效率飞起。

◆打开与浏览资源商店

找到入口。

  1. 【方式1】在 Unity 编辑器顶部菜单：【窗口 Window】→【通用 General】→【资源商店 Asset Store】，打开商店窗口。
  2. 【方式2】直接浏览器访问 assetstore.unity.com（需登录账号）。
  3. 在商店里按分类浏览：3D 模型、2D、音频、材质、工具等。
  4. 顶部搜索框可搜索关键词，如输入“free rock”找免费岩石模型。
  5. 结果中可勾选【Free 免费】过滤，只显示免费资源。
  6. 【注意】：新版 Unity（2022+）商店已并入 Package Manager 的“我的资源”页签，但仍可通过浏览器访问并“Add to My Assets”。
💡
新手阶段先下载“免费”资源练手，避免误买。下载前看评分和图片预览。

◆获取并导入资源

下载到导入全流程。

  1. 在资源详情页点击【Add to My Assets 添加到我的资源】。
  2. 【下载】后，回到 Unity：菜单【窗口】→【包管理器 Package Manager】。
  3. 在 Package Manager 窗口点击左侧【我的资源 My Assets】。
  4. 列表里找到刚添加的资源，点击右侧【下载 Download】→ 下载完成后点【导入 Import】。
  5. 弹出导入选择框，保持全选，点【Import】。
  6. 导入完成后，Project 里出现该资源的文件夹，可正常使用了。
  7. 若资源是 .unitypackage 文件：双击它，或菜单【资源】→【导入包】→【自定义包】选择文件导入。
⚠️
导入第三方资源前先看描述：是否需要特定版本、是否有依赖，避免冲突报错。

⚠常见错误与排查

⛔
错误：Package Manager 里找不到“我的资源”？
原因：未登录或版本差异
解决：确认 Package Manager 右上角已登录账号；新版入口在“我的资源 My Assets”页签。

课后小任务（做出来才算真的学会）

  • 添加后通过 Package Manager 导入
  • 把导入的模型放进场景查看
