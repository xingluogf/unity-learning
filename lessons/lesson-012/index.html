🎯本节学习目标

  • 理解 Game 视图与 Scene 视图的区别

🚀课程导读

Game 视图展示“玩家看到的世界”。本课教你如何控制它，并在运行时调试游戏。

◆Game 视图基础

找到它、理解它。

  1. 点击场景视图顶部的【Game】标签，切换到游戏视图。
  2. Game 视图通常没有内容（因为我们还没做任何 UI/操作），但能看到摄像机视野。
  3. 注意 Game 视图左上角有一行控制：Aspect（画面比例）、分辨率、缩放、静音、全屏。
  4. 【Aspect】下拉：可选 16:9、4:3、Free Aspect（自由比例）等。做手机游戏时选 9:16，做 PC 游戏选 16:9。
  5. 【缩放比例】：100% 查看实际大小；选小比例可看到全貌。
  6. 全屏按钮：让游戏视图占满整个窗口，方便观察。
💡
Game 视图的分辨率取决于你选择的 Aspect；最终发布时的实际分辨率由 Build Settings 决定（第 281 课）。

◆播放控制

顶栏的三个“播放器按钮”。

  1. 【▶ Play】播放：进入运行模式，启动游戏循环，所有 Update 开始执行。
  2. 【⏸ Pause】暂停：冻结运行状态，便于观察当前画面。
  3. 【Step（跳过帧）】按钮：暂停状态下每点一次前进一帧，逐帧排查动画/逻辑问题超好用。
  4. 【■ Stop】停止：退出运行模式，一切回到进入前的状态。
  5. 运行中修改任何 Inspector 数值都会在停止后还原——所以想“改完再看效果”，请先停止再改。
  6. 运行中的 Hierarchy 里会多出运行时生成的对象，停止后消失，属正常现象。
⚠️
强烈建议：运行时不要改脚本/资源（会自动重载导致报错）。先在编辑器里改好再运行。

⚠常见错误与排查

⛔
错误：点播放后一直黑屏？
原因：摄像机无目标或场景为空
解决：确认场景里有 Main Camera 且朝向有物体；或检查是否误删场景内容。

★动手练习

课后小任务（做出来才算真的学会）

  • 把 Aspect 切换为 16:9 与 9:16，观察画面变化
  • 播放一个物体下落，中途按暂停，再用 Step 逐帧看位置
