🚀课程导读

有了 Hub 这个“应用商店”，现在去“商店”里下载 Unity 引擎本体（一个很大的软件，几 GB）。安装过程较长，但只需这一次。

◆选择并安装引擎版本

关键步骤：选对版本。

  1. 打开 Unity Hub，点击左侧菜单的【安装 Install】标签页。
  2. 点击页面右侧的【安装编辑器 / Install Editor】按钮（或蓝色大按钮）。
  3. 出现版本列表。推荐选择最新的【长期支持版 LTS】（标签上有 LTS 字样），如 2022.3 LTS 或 2023.2 LTS。LTS = 最稳定、教程资料最多的版本。
  4. 勾选该版本，点击【安装 / Install】。
  5. 接下来是【添加模块】页面（Add modules），默认已勾选几个核心模块，我们额外勾选：☑ 中文语言包（Localization）、☑ Windows Build Support（发布 Windows 用）、☑ Microsoft Visual Studio（内置代码编辑器，强烈推荐勾选）。
  6. 如果你电脑内存/硬盘紧张，可暂时不勾其他平台模块，之后随时能补装。
  7. 点击【安装 / Install】，开始下载（约 3-5GB，取决于网络需 20-60 分钟）。
  8. 下载完成后，Hub 的【安装】列表里会出现该版本，右侧显示【打开 / Open】按钮，说明引擎安装成功。

◆激活个人版许可证

免费使用 Unity 的关键一步。

  1. 安装完第一个编辑器后，Unity 通常会自动弹窗提示激活许可证；若没弹，手动操作：Hub 左下角【设置】→【许可证 License】→ 点击【添加 / Add】。
  2. 选择【获取免费的个人版许可证 / Get a free personal license】。
  3. 浏览器会打开授权页面，登录你的账号，点击【同意 / Agree】授权条款。
  4. 授权完成后回到 Hub，许可证页面显示【个人版 Personal · 激活】状态，右上角可能出现“Unity Personal”字样。
  5. 提示：个人版免费条件——你的公司年收入低于 20 万美元（个人学习完全免费），且画面会带一个“Made with Unity”小 Logo，完全不影响学习。
  6. 现在点 Hub 里的【打开】，就能看到引擎启动画面并进入编辑器了（第一次启动较慢，属正常）。
⚠️
许可证是一次性激活的，正常使用中不需要反复激活；若以后提示“许可证过期”，重新【添加】即可。
💡
磁盘空间不足时，可删掉 Hub 中不用的旧版本引擎（安装列表→…→卸载），节省几十 GB。

⚠常见错误与排查

⛔
错误：下载到一半失败/卡住？
原因：网络波动或磁盘空间不足
解决：确认磁盘剩余 > 20GB；在 Hub 中点击该版本→【重试】；实在不行换个时段或关闭代理软件再试。
⛔
错误：没有看到中文语言包模块？
原因：模块列表未加载全
解决：点击“语言”分类查看；找不到就先不装，不影响学习，界面可后续单独补装。
