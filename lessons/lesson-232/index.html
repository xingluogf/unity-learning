🚀课程导读

不用 Blender 也能在 Unity 里“捏”模型——ProBuilder 编辑器内置建模工具。本课掌握。

◆安装与基础

建模工具包。

  1. 【安装】Window → Package Manager → 搜 ProBuilder → Install。
  2. 【窗口】Tools → ProBuilder → ProBuilder Window 打开工具栏。
  3. 【创建】在 ProBuilder 面板点 New Shape → 选择体（Cube/圆柱/门/楼梯等）。
  4. 【编辑】选中物体，用 Select/Vertex/Edge/Face 模式编辑。
  5. 【选择模式】工具栏：Object（整体）/ Vertex（顶点）/ Edge（边）/ Face（面）模式。
  6. 【挤出】选面 → 点 Extrude（挤出）拉高/拉出墙体。
  7. 【切割】Cut Tool 切面分割。
  8. 【合并】多物体用 Merge/Boolean 合并。
  9. 【注意】ProBuilder 生成的物体是“ProBuilder Mesh”，可 Convert to Mesh 转普通。
  10. 【完成】建模工具“上手”了！
💡
ProBuilder = Unity 内置“建模笔”：挤出/切割/编辑面，做原型与简单模型。

◆搭建墙体与家具

直接做房间内容。

  1. 【墙体】用 Cube 拉长拉高做墙；用 Extrude 从地板“长出”墙（选顶面挤出）。
  2. 【门窗】在墙上用 Cut 或布尔挖出洞。
  3. 【楼梯】用 ProBuilder 的 Stairs 形状一键生成楼梯。
  4. 【家具】Cube 组合：桌子（面板+4 腿）、椅子（座+背+腿）。
  5. 【桌椅】用基础体拼装成“能坐的椅子”。
  6. 【材质】给每个面/物体上材质（第 188 课）。
  7. 【碰撞】ProBuilder 物体加 Collider（Convex Mesh Collider 或组合 Box）。
  8. 【优化】Convert to Mesh + 加 Collider 用于正式场景。
  9. 【测试】场景里放上自建物体，角色可互动。
  10. 【完成】你“造”出了自己的 3D 内容！
  11. 【注意】复杂模型（角色/高面数）用外部软件，ProBuilder 做场景道具。
✅
ProBuilder 日常三件：Extrude 挤出、Stairs 楼梯、Cube 拼家具。场景道具全能造。

⚠常见错误与排查

⛔
错误：ProBuilder 物体不能碰撞？
原因：没加 Collider
解决：给 ProBuilder 物体加 Mesh Collider（勾 Convex 或组合 BoxCollider）。
