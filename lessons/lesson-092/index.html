🚀课程导读

碰撞体决定“物体哪里可以被撞、撞到的范围是什么形状”。选对碰撞体，物理才准确又高效。

◆常见碰撞体类型

按形状选。

  1. 【Box Collider 盒体】：长方体碰撞，适合盒子、墙、箱子，性能好、最常用。
  2. 【Sphere Collider 球体】：球形碰撞，适合球、圆角物体。
  3. 【Capsule Collider 胶囊】：圆柱+半球，适合角色（人形、柱子）。
  4. 【Mesh Collider 网格】：用模型的实际网格做碰撞，最精确但最耗性能（静态环境可用）。
  5. 【其他】Terrain Collider（地形）、2D 系列（第 204 课）。
  6. 【添加】Add Component → 搜 Collider；Unity 给基本几何体自动加对应碰撞体。
  7. 【Is Trigger 触发器】：勾选后不再“阻挡”，而是触发事件（第 96 课）。
  8. 【Center/Size】：调整碰撞体的位置与大小。
  9. 【注意】带刚体的物体必须有碰撞体才能被撞；静态物体（无刚体）有碰撞体即可阻挡。
💡
性能优先级：Box/Sphere/Capsule 简单碰撞 >> Mesh 精确碰撞。能用简单的绝不用网格。

◆碰撞体与刚体的配合

正确组合。

  1. 【静态障碍】无刚体 + 有碰撞体：不可移动，能阻挡其他物体（墙、地面）。
  2. 【动态物体】有刚体 + 有碰撞体：受重力、可被推（箱子、球）。
  3. 【触发区域】有刚体（或脚本） + Is Trigger 碰撞体：不阻挡，只触发事件（检测进入区域）。
  4. 【复合碰撞体】一个对象挂多个碰撞体：如“人形”用多个胶囊/球拼出身体形状（比单个大盒子更贴合）。
  5. 【子对象碰撞体】碰撞体也可挂在子对象上，组成复杂结构（每个子碰撞体独立）。
  6. 【实战】给一个“茶壶”模型（复杂形状）添加多个 Box Collider 组合出近似碰撞。
  7. 【Mesh Collider 优化】静态场景用 Convex 勾选可移动但成本高；一般只用于静态。
✅
碰撞体选择口诀：方盒子用 Box、圆的用 Sphere、人形用 Capsule、复杂静态才用 Mesh。

⚠常见错误与排查

⛔
错误：物体穿过地面掉下去？
原因：地面无碰撞体，或刚体速度过快
解决：确认地面有碰撞体；速度过快可开启刚体 Collision Detection 的 Continuous（第 97 课）。
