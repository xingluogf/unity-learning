🚀课程导读

“原型变游戏”——本课把内容做满：多关、敌人、道具、UI、音效、存档全上。

◆内容扩充

“更丰富”。

  1. 【多关卡】做 3 关：不同平台布局、难度递增（第 218 课关卡设计）。
  2. 【敌人】巡逻、追击两种（第 211 课）；放不同位置。
  3. 【道具】加速/无敌/加血（第 212 课）。
  4. 【检查点】每关中段放旗帜（第 218 课）。
  5. 【Boss】（可选）第 3 关加一个简单 Boss（多血敌人+弹幕）。
  6. 【难度曲线】每关引入新机制：第1关跳跃、第2关敌人、第3关道具组合。
  7. 【完成】内容“丰富了”。
  8. 【注意】新机制“先试用再组合”（第 218 课教学节奏）。
💡
内容公式：关卡递增难度 + 每关一个新机制 + 敌人/道具点缀。丰富又有序。

◆系统整合

“全套”上齐。

  1. 【UI】主菜单、暂停、结束、HUD 全套（第 161-163/170 课）。
  2. 【音效】BGM + 跳跃/金币/受伤音效（第 178/221 课）。
  3. 【特效】跳跃尘土、金币闪光、死亡粒子（第 186-200 课）。
  4. 【存档】检查点自动存档 + 继续游戏（第 220/246 课）。
  5. 【设置】音量滑块（第 177 课）。
  6. 【架构】GameManager/AudioManager/UIManager 单例（第 274 课）。
  7. 【对象池】子弹/特效走池（第 269 课）。
  8. 【测试】全系统联调：菜单→玩→存档→暂停→结束→继续。
  9. 【完成】“游戏”成型！
  10. 【注意】每加一个系统就测一次，别攒一起。
  11. 【里程碑验收】3 关 + 全套系统 = M2 完成。
  12. 【推荐】整合阶段最考验架构，按第 274 课分层做。
✅
系统整合 = UI 全套 + 音效 + 特效 + 存档 + 单例架构。齐了才叫“游戏”。

⚠常见错误与排查

⛔
错误：系统互相打架？
原因：耦合严重
解决：用单例/事件解耦（第 274 课）；各系统独立测试再联调。
