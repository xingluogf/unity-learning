2D 游戏的“走路动画”其实是快速切换一组图片（序列帧）。本课制作第一个 2D 帧动画。

◆2D 帧动画原理

“翻页动画”。

  1. 2D 动画 = 按顺序快速切换 Sprite（精灵图片），每秒 N 帧形成动感。
  2. 【素材】一组连续的精灵图（如角色走路的 8 帧）。
  3. 【制作方式】把一组 Sprite 拖到一个对象上，生成 Animation Clip。
  4. 【SpriteRenderer】2D 对象的显示组件（第 202 课），动画改变它的 sprite 属性。
  5. 【帧率】动画片段的时间轴决定播放速度，一般 8-12 帧/秒。
  6. 【特点】无需骨骼、简单直观，适合像素/手绘风格。
  7. 【对比】骨骼动画（2D 用 Spine/2D Animation 包）可变形更灵活，进阶。
  8. 【用途】角色动作、特效帧、UI 动画、翻页。
💡
2D 帧动画 = 老式“翻页册”，简单高效，2D 游戏主力。

◆制作序列帧动画

上手做。

  1. 【准备素材】导入一组精灵图（如 walk_0、walk_1...walk_7），设置 Texture Type 为 Sprite（第 39 课）。
  2. 【建对象】场景里创建空对象，加 SpriteRenderer，把第一帧 sprite 赋上。
  3. 【打开 Animation 窗口】选中对象，点 Create 命名 Walk，保存。
  4. 【添加关键帧】在时间轴 0 秒，把 SpriteRenderer 的 Sprite 属性设为第 1 帧，点添加关键帧。
  5. 【下一帧】时间轴移到 0.1 秒，Sprite 设为第 2 帧；重复直到最后一帧。
  6. 【循环】选中 .anim 勾选 Loop Time（第 129 课）。
  7. 【预览】播放：角色“走起来”了！
  8. 【快速法】在 Project 里多选所有帧图片，直接拖到场景/对象上，Unity 自动生成动画与 Animator（便捷方式）。
  9. 【优化】帧数越多越细腻但越占资源，按需。
  10. 【注意】帧的切换时间决定动作速度，可用“样条曲线”整体调快慢。
✅
最省事路径：多选序列帧图片 → 拖到场景 → 自动成动画。一拖搞定。

⚠常见错误与排查

⛔
错误：精灵动画不播放？
原因：SpriteRenderer 没被动画驱动，或 Loop 未开
解决：确认动画片段记录了 Sprite 属性；勾选 Loop Time；确认 Animator 有该状态。
