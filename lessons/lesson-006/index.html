新建你的第一个 Unity 项目（3D Core 模板）

🚀课程导读

环境搭好了，现在创建第一个项目。别小看这一步：项目命名与路径规范能避免后续 90% 的麻烦。

◆创建项目

跟着点，3 分钟搞定。

  1. 打开 Unity Hub，点击左侧【项目 Projects】标签页。
  2. 点击右上角【新建项目 / New project】按钮。
  3. 在模板选择界面，能看到很多模板：3D Core、2D Core、3D (Built-In Render Pipeline)、2D (URP) 等。我们选【3D Core】——这是最经典、最通用、新手最推荐的 3D 模板。
  4. 【项目名称 Project name】栏：输入项目名。命名规则：只能使用英文、数字、下划线，不能用中文、空格、特殊符号！例如 MyFirstGame、Lesson06_Test。
  5. 【位置 Location】栏：点击【浏览 / Browse】选择项目存放目录。建议单独建一个文件夹专门放 Unity 项目，例如 D:\UnityProjects（注意路径同样别带中文）。
  6. 【编辑器版本 Editor Version】：确认显示的是你刚安装的 LTS 版本。
  7. 点击右下角【创建项目 / Create project】，Unity 会开始创建（首次需 1-3 分钟）。
  8. 创建完成后自动进入 Unity 编辑器主界面。恭喜，你的第一个项目诞生了！
⛔
项目名和路径千万别带中文/空格！否则会出现各种诡异的编译、导入错误，这是新手第一大坑。
💡
模板决定了默认的渲染管线与场景内容。3D Core = 内置渲染管线，最适合入门。

◆认识默认场景内容

看看新项目里有什么。

  1. 进入编辑器后，中间是【Scene 场景视图】，里面默认有一个方块（Cube）、一个方向光（Directional Light）和一个摄像机（Main Camera）。
  2. 右上角【层级 Hierarchy】面板里能看到这三个对象：Main Camera、Directional Light、Cube。
  3. 按住鼠标右键拖动可旋转视角，按住鼠标中键（滚轮）拖动可平移视角，滚动滚轮可缩放。
  4. 找到游戏对象后，看到的是 Unity 自带的默认 3D 场景。
  5. 本课只需确认“能进入、能看到场景”即可，具体操作下一课系统学习。
💡
以后每次做练习都建议新建独立项目，避免资源混乱。

⚠常见错误与排查

⛔
错误：创建项目时提示路径无效？
原因：路径包含中文或非法字符
解决：把路径改为全英文目录，例如 D:\UnityProjects\MyFirstGame。
⛔
错误：进入项目后全是英文看不懂？
原因：未安装/未启用中文语言包
解决：菜单 Edit→Preferences→Languages→Language 选择“中文”，重启编辑器即可（需已安装中文语言包）。

★动手练习

课后小任务（做出来才算真的学会）

  • 创建名为 MyFirstGame 的 3D Core 项目
  • 在场景里用鼠标右键+中键转一圈视角
  • 在 Hierarchy 中数出默认有几个对象
