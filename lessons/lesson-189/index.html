Standard Shader 是“万能材质”：从金属到玻璃到发光。本课把它调明白。

◆Rendering Mode 渲染模式

透明还是不透明。

  1. Standard Shader 的【Rendering Mode】决定透明度：
  2. 【Opaque】不透明（默认）：金属、石头、木头。
  3. 【Cutout】裁剪：贴图有全透明区域（叶子、铁丝网，边缘硬）。
  4. 【Fade】淡出：整体半透明渐隐（玻璃、幻影，可调 Albedo 的 A 通道）。
  5. 【Transparent】透明：真透明（玻璃、水面），可控制透明度。
  6. 【切换】选中材质，Rendering Mode 下拉切换。
  7. 【透明贴图】用带 Alpha 通道的 PNG（第 39 课）。
  8. 【实例】玻璃窗：Transparent + Albedo 浅蓝 + Smoothness 高 + 半透明。
  9. 【注意】透明物体有排序问题，多透明物重叠时用 Render Queue（进阶）。
💡
渲染模式四选一：Opaque 实心、Cutout 抠空、Fade 渐隐、Transparent 透明。

◆金属度/光滑/自发光

调出“质感”。

  1. 【Metallic 金属度】
  2. 0：非金属（木头、布料）——高光散、柔和。
  3. 1：金属（钢、金）——高光集中、反射强。
  4. 【Smoothness 光滑度】
  5. 0：粗糙（磨砂、石头）——反射糊。
  6. 1：光滑（玻璃、镜面）——反射清晰。
  7. 【组合实验】
  8. 金属抛光（Metallic 1 + Smooth 0.9）= 不锈钢。
  9. 陶瓷（Metallic 0 + Smooth 0.7）= 光滑塑料/釉面。
  10. 粗糙石头（Metallic 0 + Smooth 0.1）。
  11. 【Emission 自发光】勾选 Enable Keyword → Color 设发光色/强度。
  12. 适合：灯、霓虹、科幻面板（配合发光贴图）。
  13. 【Albedo 贴图】放一张纹理，材质立刻“有细节”（第 184 课）。
  14. 【实践】做一个金属球 + 一个玻璃球 + 一个霓虹灯牌，对比质感。
  15. 【注意】自发光物体不受光照影响（自己发光）。
✅
质感配方：金属+光滑=金属、非金属+光滑=陶瓷、非金属+粗糙=石头。记住三个样板。

⚠常见错误与排查

⛔
错误：透明材质变成半透明但看不见？
原因：Albedo 的 A 通道太透明或 Render Queue 问题
解决：用 Transparent 模式并调 Albedo 颜色 A 值；检查是否被遮挡。
