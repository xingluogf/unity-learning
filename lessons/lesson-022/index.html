🚀课程导读

Transform 控制对象的位置、旋转、缩放，是出现频率最高的组件。把它的数值逻辑吃透。

◆Transform 三大属性

选中任意对象，右侧最顶部就是 Transform。

  1. 【Position 位置】：三个数字 (X, Y, Z) 表示对象在 3D 空间中的坐标，单位是“米”。
  2. X 轴 = 左右，Y 轴 = 上下，Z 轴 = 前后。原点 (0,0,0) 是世界的中心。
  3. 【Rotation 旋转】：三个角度 (X, Y, Z) 表示对象绕各轴的旋转量，单位“度”。
  4. 旋转顺序与“万向锁”等进阶问题后面讲，先会用：把 Y 改成 90 就是水平转 90 度。
  5. 【Scale 缩放】：三个数字表示各轴放大倍数，1 = 原大小，2 = 2 倍，0.5 = 一半。
  6. 把 Scale 三个值设成相同数字是“等比缩放”（如 2,2,2），不同则拉伸变形。
  7. 【全局/局部坐标】切换：Transform 显示的是“局部坐标”（相对父对象）；勾选工具栏的 Global/Local 可看全局。
💡
想把物体放到某精确位置：直接在 Position 输入数字比手动拖更准确，例如 (0, 1, 0) 表示站在地面 1 米高。

◆实战：精确摆放

用数字控制位置，搭一个“台阶”。

  1. 创建 3 个 Cube，分别命名为 Step1、Step2、Step3。
  2. 选 Step1，把 Position 设为 (0, 0.5, 0)，Scale 设为 (1, 1, 1)。
  3. 选 Step2，Position 设为 (1.5, 0.5, 0)，Scale 设为 (1, 1, 1)。
  4. 选 Step3，Position 设为 (3, 0.5, 0)，Scale 设为 (1, 1, 1)。
  5. 在场景里调整视角，观察三个方块依次排开。
  6. 再把 Step1 的 Rotation 的 Y 改为 45，方块原地旋转 45 度。
  7. 最后把 Step3 的 Scale 改为 (1.5, 1.5, 1.5)，它变大一圈。
  8. 体会：数字就是“尺子”，精确摆位全靠它。
⚠️
Y 坐标“1”是从地面向上 1 米。把方块放地面上时，高度 = 方块高度的一半（如 1 米高方块放 Y=0.5）。

⚠常见错误与排查

⛔
错误：物体明明在原点却看不见？
原因：物体可能被缩放为 0 或压在相机后面
解决：把 Scale 改成 1；把 Position 改到相机前方（如 (0,1,5)）。

★动手练习

课后小任务（做出来才算真的学会）

  • 用数值把 5 个方块摆成一条直线
  • 把其中一个方块精确旋转 90 度
  • 把一个方块等比放大到 2 倍
