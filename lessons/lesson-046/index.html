◆脚本在游戏里做什么

脚本 = 给对象写的“行为说明书”。

  1. 没有脚本：场景是静止的“模型展”；有脚本：物体能响应输入、计算、变化。
  2. 脚本（C#）附加到 GameObject 上，作为组件运行，每一帧执行我们写的逻辑。
  3. 常见任务：让角色移动、检测碰撞、控制 UI、管理游戏流程、计算分数……全是代码。
  4. Unity 里一个“脚本”通常对应一个类（Class），写好后像其他组件一样拖到对象上。
  5. 【学习路线】：先学 C# 语法（本章 30 课），再学 Unity API（如何让语法操控场景对象），循序渐进。
💡
编程 = 把人类逻辑翻译成电脑能执行的精确指令。别怕，语法很简单。

◆C# 是什么

认识这门语言。

  1. C#（读“C Sharp”）是微软开发的一门现代化编程语言，语法清晰、功能强大。
  2. Unity 使用 C# 作为官方脚本语言（也可用少量其他语言，但主推 C#）。
  3. C# 是“面向对象”语言：一切围绕“类与对象”组织（第 63-68 课讲）。
  4. 它与 Java 相似、比 C++ 简单安全（自动内存管理）。
  5. 学会 C# 后，也能用于开发 .NET 应用，技能通用。
  6. 【工具】：Unity 自带 Visual Studio 编辑器（代码智能提示、调试），或 VS Code。
  7. 本章将一步步从变量学到类与继承，全部基于 Unity 环境实战。
✅
建议本阶段每学一课语法，就在 Unity 里新建脚本跑一遍，动手最重要。
