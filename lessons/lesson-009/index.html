🎯本节学习目标

  • 把 Unity 界面切换为中文
  • 了解常用偏好设置项
  • 掌握界面字号与主题调整

🚀课程导读

Unity 支持简体中文界面。本课带你切换语言并调好最常用的偏好设置，让编辑器更趁手。

◆切换为中文界面

需要先安装中文语言包（若安装引擎时已勾选，直接执行第 3 步）。

  1. 检查是否装了语言包：Unity Hub →【安装】→ 你的版本右侧 … →【添加模块】→ 勾选【中文语言包】→【完成】。
  2. 等待语言包下载安装完成。
  3. 打开 Unity 项目，点击顶部菜单【Edit】→【Preferences】（偏好设置）。
  4. 在弹出的窗口中点击【Languages】分类。
  5. 在右侧找到【Editor Language】，把 English 改为【简体中文】。
  6. 点击窗口右下角【Apply / 应用】→【OK】，编辑器会重启并变成中文界面。
  7. 现在顶栏显示【文件 File】【编辑 Edit】【资源】等中文菜单，成功！
💡
不同版本菜单位置可能略不同（Preferences 也可能在 Edit 或 菜单不同层级），关键字搜索“Language”即可找到。

◆常用偏好设置

按需调整，提升体验。

  1. 【Colors / 颜色】：可自定义场景背景色等，新手不用改。
  2. 【General → Auto Refresh】：保持开启（自动刷新资源，改动脚本自动编译）。
  3. 【General → Script Changes While Playing】：建议选“停止播放并重载”（防止边玩边改脚本报错混乱）。
  4. 【GI Cache】：缓存光照烘焙数据，保持默认。
  5. 【External Script Editor】：选择你习惯的代码编辑器，默认 Visual Studio 即可；可换成 VS Code。
  6. 【Theme / 主题】：在 Preferences→General→Editor Theme 可切换浅色/深色主题，深色更适合长时间盯屏幕。
⚠️
把脚本编辑器换成 VS Code 的同学，需要在 VS Code 里安装 C# 与 Unity 扩展插件才能有智能提示，否则还是先用自带的 Visual Studio。

⚠常见错误与排查

⛔
错误：Preferences 里找不到 Language 选项？
原因：中文语言包未安装
解决：回 Unity Hub 给该版本【添加模块】勾选中文语言包，装完重启项目即可。
⛔
错误：切换中文后部分菜单仍是英文？
原因：语言包覆盖不完全
解决：正常现象，核心菜单已是中文，个别插件/窗口保持英文不影响使用。
