🚀课程导读

“脚步落在音乐点”“刀砍中才响”——音画同步靠动画事件。本课专业同步。

◆动画事件触发音效

在动画关键帧“点炮”。

  1. 【原理】动画事件（第 135 课）在特定帧调用方法，方法里播音效=精确同步。
  2. 【脚步】在走路动画的“脚落地帧”加事件：
  3. public void Footstep(string foot) {
  4. AudioManager.Instance.PlaySFX(“Footstep”, 0.5f); // 随机变体
  5. }
  6. 【命中】攻击动画“挥到一半”加事件：
  7. public void AttackHit() {
  8. AudioManager.Instance.PlaySFX(“SwordHit”);
  9. // 同时可加粒子/伤害判定
  10. }
  11. 【落地】跳跃落地动画事件：PlaySFX(“Land”)。
  12. 【方法要求】方法挂在该对象、public、与事件名字一致（第 135 课）。
  13. 【精确】拖动事件菱形对准“该响的帧”。
  14. 【测试】走路/攻击/落地，音效与动作同步。
  15. 【完成】音画“同步”。
  16. 【注意】事件方法名拼错不报错但无声——核对。
  17. 【推荐】“时机敏感”的音效全走动画事件。
💡
音画同步 = 动画事件（关键帧“点炮”）+ 音效库（按名播）。两件套。

◆动态音量与音画节奏

让同步“自然”。

  1. 【脚步随机】脚步音效随机 Pitch（0.95-1.05）+ 随机变体（第 173 课）——像真走路。
  2. 【走路/跑步区分】不同动画事件用不同音效名（Walk/Footstep、Run/FootstepFast）。
  3. 【地面材质】踩草地/木板不同音（射线检测地面 + 切音效，进阶）。
  4. 【攻击节奏】命中音效滞后攻击动画一点点（0.02s 延时）更像真实挥砍。
  5. 【音量随距离】3D 音效自动衰减（第 175 课）。
  6. 【UI 音效】按钮/菜单音效用 2D（Spatial 0），与动画无关。
  7. 【混响】（进阶）AudioMixer 加 Reverb 让室内音效有“空间感”。
  8. 【测试】完整“走-跑-跳-攻”音效节奏舒服。
  9. 【完成】同步“自然”。
  10. 【注意】音效别与动画“抢”（太密集会糊），控制频率。
  11. 【推荐】给每个“会动”的角色配一套脚步声效。
✅
同步进阶 = 事件分脚步/跑步 + 地面材质切音效 + 随机音调。真实感拉满。

⚠常见错误与排查

⛔
错误：攻击没声音？
原因：动画事件没加或方法名不对
解决：在 Animation 窗口关键帧加事件；核对 Function 名；方法在该对象上。
