运算符让数据产生变化与判断。它们是代码的“动作”。

◆算术运算符

做数学运算。

  1. 【+ 加】【- 减】【* 乘】【/ 除】：int a = 10; int b = 3;
  2. a / b 得 3（整数相除只保留整数部分），要得小数需 float 参与：10f / 3 得 3.33…。
  3. 【% 取余（求模）】：a % b 得 1（10 除以 3 余 1）。用于判断奇偶、循环动画等。
  4. 【+ 也可拼接字符串】："a" + "b" 得 "ab"。
  5. 【优先级】：先乘除后加减，括号 ( ) 最优先：2 + 3 * 4 = 14；(2 + 3) * 4 = 20。
💡
整数除法容易踩坑：两个 int 相除结果还是 int。需要小数时让其中一个数变成 float。

◆比较与逻辑运算符

产生 true/false 判断。

  1. 【比较运算符】：==（等于）、!=（不等于）、>（大于）、<（小于）、>=（大于等于）、<=（小于等于）。
  2. 比较结果是一个 bool：int a = 5; a > 3 得 true；a == 3 得 false。
  3. 【注意】：判断相等用两个等号 ==，单个 = 是赋值！这是新手高频错误。
  4. 【逻辑运算符】：&&（并且）、||（或者）、!（取反）。
  5. (a > 3) && (a < 10)：a 大于 3 且小于 10，得 true。
  6. (a < 0) || (a > 100)：a 小于 0 或大于 100 才 true。
  7. !(a > 3)：对结果取反，得 false。
  8. 短路特性：&& 左边为 false 就不看右边；|| 左边为 true 就不看右边。
⛔
一个等号 = 是赋值，两个等号 == 才是比较！写错会让逻辑永远“成立”，Debug 到怀疑人生。

◆赋值运算符与自增

简化写法。

  1. 【=】赋值：int x = 10;
  2. 【+=】【-=】【*=】【/=】：x += 5 等价于 x = x + 5；x -= 3 等价于 x = x - 3。
  3. 【++ 自增】【-- 自减】：x++ 等价于 x = x + 1；x-- 等价于 x = x - 1。
  4. x++ 与 ++x 区别：x++ 先返回原值再加；++x 先加再返回（一般循环里用 x++ 即可）。
  5. 实战组合：int score = 0; score += 10; // 得 10；score++; // 得 11。
  6. 用于计分、生命值增减、循环计数等。
💡
score += 10 比 score = score + 10 更简洁，也更快，习惯用它。

⚠常见错误与排查

⛔
错误：把 == 写成 = 导致逻辑永远正确？
原因：赋值表达式返回 true
解决：检查条件判断处是否用了双等号；编辑器/编译器也会给出建议。

  • 写一段判断：分数大于等于 60 且小于 90 输出"及格"
  • 用 += 把分数累加 3 次
