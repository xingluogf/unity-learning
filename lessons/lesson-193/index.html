🚀课程导读

天空背景 + 环境光决定了场景的“主色调”。本课用一分钟改变整个氛围。

◆天空盒 Skybox

天空“贴纸”。

  1. 【什么是天空盒】包裹场景的远景“盒子”，决定背景（天空/星空/黄昏）。
  2. 【设置】Window → Rendering → Lighting → Environment 页签。
  3. 【Skybox Material】选择天空盒材质：
  4. ① 默认 Skybox：可选预设（Day/黄昏/Night）。
  5. ② 六面天空盒：6 张贴图（四边+上下）——立方体贴图（第 41 课）。
  6. ③ 程序化天空盒：只调参数（太阳强度、雾）。
  7. 【设置方法】Project 找到 Skybox 材质 → 拖到 Lighting 的 Skybox Material 槽。
  8. 【自定义】用“Panorama”全景图（360 度图）生成 Cubemap，做全景天空。
  9. 【注意】没设 Skybox 时背景为纯色（Camera Clear Flags）。
  10. 【效果】换一个黄昏天空盒，整个场景氛围大变。
  11. 【实战】给场景换一个“黄昏”或“星空”天空盒。
  12. 【天光】Skybox 还提供天光（环境光来源之一，见下）。
💡
换天空盒 = 换“世界观”：一个黄昏天空盒瞬间让场景有电影感。

◆环境光与雾

全局氛围调色。

  1. 【环境光 Ambient】物体背光面的“基础亮度”，来自天空/环境。
  2. Lighting → Environment 的 Ambient Mode 与 Ambient Light：
  3. Skybox（从天光取色）/ Color（统一颜色）/ Gradient（天空-赤道-地面三色渐变）。
  4. 【调暗环境光】让场景更有对比；调亮让场景更柔和。
  5. 【雾效 Fog】大气透视：远处物体“蒙雾”更真实/有氛围。
  6. Window → Rendering → Lighting → Fog 勾选：
  7. Fog Mode（Linear 线性/Smooth 指数）；Fog Color（雾色）；Fog Density/Start/End。
  8. 【示例】清晨白雾（白色线性雾）、黄昏橙雾。
  9. 【雾对性能】雾效便宜，随便开。
  10. 【注意】雾会影响远处物体可见性，别把玩家视野全遮。
  11. 【实战】给黄昏场景加橙色薄雾，氛围拉满。
  12. 【推荐】环境光+雾是“低成本高质感”的万能氛围手段。
✅
氛围三件套：天空盒定背景、环境光定基调、雾效定深度。三分钟改头换面。

⚠常见错误与排查

⛔
错误：天空盒显示黑色？
原因：天空盒材质未设置或 Cubemap 缺失
解决：在 Lighting → Environment 指定有效的 Skybox 材质；确认贴图导入正确。
