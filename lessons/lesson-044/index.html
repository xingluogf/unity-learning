🚀课程导读

把做好的模型/脚本/整个场景分享给朋友，或备份到网盘，靠的就是“导出包”。本课三分钟学会。

◆导出资源包

打包带走。

  1. 在 Project 窗口选中要导出的内容（可多选：一个文件夹/多个资源）。
  2. 点击菜单【资源 Assets】→【导出包 Export Package…】。
  3. 弹出导出设置窗口，列表显示将包含的资源，保持勾选全部，点【Export】。
  4. 选择保存位置并命名（如 MyPrefabs.unitypackage），点保存。
  5. 导出成功！这个 .unitypackage 文件就是一个“资源压缩包”。
  6. 注意：导出的是“资源”，不包含未保存的场景修改；导出前先保存场景。
💡
导出整个项目分享给他人：选中 Assets 根目录导出即可（但会较大）。

◆导入资源包

接收别人给的包。

  1. 拿到 .unitypackage 文件后，放到电脑任意位置。
  2. 方式1：双击 .unitypackage 文件，Unity 自动打开导入向导。
  3. 方式2：菜单【资源 Assets】→【导入包 Import Package】→【自定义包 Custom Package…】→ 选择文件。
  4. 在导入选择窗口中，查看列表内容，保持全选，点【Import】。
  5. 等待导入完成，Project 里出现对应文件夹。
  6. 导入后检查 Console：若有报错（如脚本编译错误、版本不兼容），按提示处理。
  7. 【注意】不同 Unity 版本导入老包可能提示版本升级，一般可正常使用。
⚠️
导入不认识的第三方包前先确认来源可信，避免夹带恶意脚本。

⚠常见错误与排查

⛔
错误：导入包后脚本全红？
原因：脚本引用了缺失的包/API
解决：查看 Console 报错，安装缺失依赖包，或升级/降级 Unity 版本。
