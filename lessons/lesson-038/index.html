🚀课程导读

纯色材质太单调，贴图让物体拥有真实的细节（木纹、砖墙、皮肤）。本课导入第一张贴图。

◆导入贴图

图片拖进 Project。

  1. 准备一张图片（网络找一张木纹/砖墙图，或系统自带图片）。
  2. 在 Project 的 Textures 文件夹里，把图片直接拖进去导入。
  3. 选中图片，Inspector 出现纹理导入设置。
  4. 【Texture Type 纹理类型】：一般保持 Default（默认，用作贴图）。
  5. 【Alpha Source】：图片若有透明通道，选“From Texture Alpha”；否则“None”。
  6. 【Wrap Mode】：Repeat（重复平铺，地面砖纹常用）或 Clamp（边缘拉伸）。
  7. 【Filter Mode】：Bilinear（双线性，默认）让缩放平滑。
  8. 【Max Size】：图片最大尺寸，控制内存，一般 1024/2048 够用。
  9. 点击【Apply】应用。
💡
做 UI 的图片、做精灵的图片类型不同（见第 38 课与 UI 章节），这里讲的是“世界贴图”。

◆用贴图制作材质

三步做出带纹理的表面。

  1. 在 Materials 文件夹创建新材质，命名 Wood_Mat。
  2. 把导入的木纹图片拖到材质面板的【Albedo】色块旁的方框里。
  3. 材质表面立即变成木纹；把它拖到场景里的 Cube 上，方块呈现木纹。
  4. 调节【Tiling】：在材质面板 Albedo 图片下方，把 Tiling X/Y 都改成 2，木纹重复 2 次（类似贴瓷砖）。
  5. 【Offset】：可偏移贴图起始位置。
  6. 把同一张贴图拖到多个材质/物体，复用。
  7. 进阶：木纹图 + 法线贴图（另一张黑白图）提升立体感（后续可选）。
💡
Tiling 数值大=贴图重复次数多=单个格子更小，适合大面积地板。

⚠常见错误与排查

⛔
错误：贴图在材质里显示为“空白/灰块”？
原因：贴图类型设置不对或未 Apply
解决：选中图片检查 Texture Type 是否为 Default，改完点 Apply；重新拖入 Albedo 槽。

★动手练习

课后小任务（做出来才算真的学会）

  • 导入一张木纹图并做成材质
  • 把它赋给一个地板并设置 Tiling=4
  • 体验 Repeat 与 Clamp 两种 Wrap Mode 的区别
