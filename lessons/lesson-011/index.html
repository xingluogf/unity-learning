🚀课程导读

场景视图是你在 Unity 里的“建模车间”。本课把它的所有操作讲透，这是最值得花时间熟练的技能之一。

◆鼠标导航操作（最重要）

记住这三组操作，你就能在 3D 空间里自由漫游。

  1. 【旋转视角】按住鼠标右键不放并拖动：视角绕中心旋转，像转动自己的头。
  2. 【平移视角】按住鼠标中键（滚轮按下）不放并拖动：整个视图平移。
  3. 【缩放视角】滚动鼠标滚轮：拉近拉远；或者按住 Alt + 鼠标左键拖动。
  4. 【俯视/其他视角】在场景视图右上角有一个坐标轴小方块（Gizmo）：点击箭头从不同方向看（正前/正后/俯视等）。
  5. 【聚焦对象】在 Hierarchy 里双击某个对象，或选中对象后按 F 键，视角会立刻飞过去对准它。
  6. 【绕物体旋转】选中物体后，按住 Alt + 鼠标左键拖动，视角围绕该物体旋转。
  7. 练习：在场景里放几个物体，用以上操作在它们之间“飞行”一圈。
💡
快捷键 F 聚焦非常常用！找不到物体时，选中它按 F 立刻找回。

◆场景视图顶栏工具

顶部一行小按钮，控制显示方式。

  1. 视图模式下拉框：默认是“阴影 Shadow”模式，可切换到“线框 Wireframe”，线框模式便于看清结构。
  2. 【2D/3D 切换】：2D 按钮把视图锁定为平面俯视（2D 项目常用）。
  3. 【着色模式】默认 Shaded，可选 Wireframe、Shaded Wireframe 等。
  4. 【光照开关】小灯泡图标：关闭后无光照、显示纯色，方便看清模型；但运行不受影响。
  5. 【Audio 音频/效果开关】等按钮，新手先了解即可。
  6. 【Gizmo 开关】：控制对象辅助图标（坐标轴、相机锥体等）的显示。
💡
若物体在场景里“消失”，多数是被移动到了视野外，用 Hierarchy 选中 + F 找回。

⚠常见错误与排查

⛔
错误：场景视图里物体一直在闪烁？
原因：可能是多个重叠物体或 Z-fighting
解决：检查是否同一位置堆了多个平面；新手阶段先忽略，进阶课会讲。

★动手练习

课后小任务（做出来才算真的学会）

  • 放 5 个物体，练习旋转/平移/缩放视角
  • 选中一个物体按 F，体验聚焦
  • 切换到线框模式看看物体结构
