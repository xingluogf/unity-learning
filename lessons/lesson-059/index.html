🚀课程导读

List 按下标找元素，但你想“按名字找数据”呢？字典（Dictionary）用“钥匙-值”配对，查找极快。

◆字典基础

“钥匙”开“抽屉”。

  1. 需要 using System.Collections.Generic;
  2. 创建语法：Dictionary<string, int> scores = new Dictionary<string, int>();
  3. 尖括号里第一个是“键 Key”类型，第二个是“值 Value”类型。
  4. 【添加】：scores["小明"] = 90; 或 scores.Add("小红", 85);
  5. 【取值】：int s = scores["小明"]; // 得 90
  6. 【判断键存在】：scores.ContainsKey("小明") 返回 bool，取之前先判断防报错。
  7. 【删除】：scores.Remove("小红");
  8. 【元素个数】：scores.Count。
  9. 【改值】：scores["小明"] = 95;（键已存在则覆盖）。
⛔
取不存在的键（scores["不存在"]) 会抛异常崩溃！取值前先用 ContainsKey 判断。

◆遍历与实战

遍历键值对。

  1. 遍历所有键值对：foreach (KeyValuePair<string, int> kv in scores) { Debug.Log(kv.Key + "：" + kv.Value); }
  2. 或遍历所有键：foreach (string name in scores.Keys) { ... }；遍历所有值：scores.Values。
  3. 【实战】游戏物品背包：Dictionary<string, int> inventory = new Dictionary<string, int>();
  4. inventory["金币"] = 100; inventory["药水"] = 5;
  5. 加金币：inventory["金币"] += 50;
  6. 打印背包内容：foreach (var kv in inventory) { Debug.Log(kv.Key + " x" + kv.Value); }
  7. 【适合场景】按名字查配置、玩家数据、成就表等。
  8. 字典内部无序，遍历顺序不保证插入顺序。
💡
用 var 可以简化声明：foreach (var kv in inventory)。var 让编译器推断类型。

⚠常见错误与排查

⛔
错误：报错：KeyNotFoundException？
原因：取了不存在的键
解决：取值前用 ContainsKey 判断，或用 TryGetValue（更高效）。
