◆手雷投掷

抛物线 + 引爆。

  1. 【投掷】给手雷初始速度（刚体+Impulse）：
  2. public GameObject grenadePrefab; public Transform throwPoint;
  3. public float throwForce = 10f;
  4. void Throw() {
  5. GameObject g = Instantiate(grenadePrefab, throwPoint.position, throwPoint.rotation);
  6. Rigidbody rb = g.GetComponent<Rigidbody>();
  7. rb.AddForce(throwPoint.forward * throwForce, ForceMode.Impulse);
  8. }
  9. 【抛物线】重力自动让手雷走抛物线（第 233 课 AddForce+gravity）。
  10. 【引信】Grenade 脚本：
  11. public float fuse = 2.5f;
  12. void Update() { fuse -= Time.deltaTime; if (fuse <= 0) Explode(); }
  13. 【引爆】Explode()：
  14. // 特效音效（第 200 课）
  15. ObjectPool.Instance.GetExplosion(transform.position);
  16. AudioManager.Instance.PlaySFX(boom);
  17. // 范围伤害
  18. Collider[] hits = Physics.OverlapSphere(transform.position, blastRadius);
  19. foreach (var c in hits) {
  20. Enemy e = c.GetComponent<Enemy>(); if (e != null) e.TakeDamage(50);
  21. }
  22. Destroy(gameObject);
  23. 【说明】OverlapSphere 范围内取碰撞体。
  24. 【测试】丢雷抛物线飞行、落地爆炸范围伤害。
  25. 【注意】别丢到自己（跳过玩家 tag）。
  26. 【完成】手雷“会炸”了！
💡
投掷 = 初始速度（抛物线）+ 引信计时 + OverlapSphere 范围伤害。三步。

◆弓箭与追踪弹

飞行的两种玩法。

  1. 【弓箭】箭矢有速度+碰撞：箭是刚体飞行物，命中时插在目标上：
  2. 箭脚本：rb.AddForce(forward * speed, Impulse)；碰撞时（OnCollisionEnter）停住（isKinematic）+ 插在命中点。
  3. 【命中】射中敌人扣血+音效。
  4. 【追踪弹】导弹自动锁定目标：每帧朝目标转向：
  5. Vector3 dir = (target.position - transform.position).normalized;
  6. rb.velocity = dir * speed;
  7. 【锁定】目标为空时直线飞行（第 215 课追踪弹）。
  8. 【爆炸】追踪弹命中时范围爆炸（同手雷）。
  9. 【选择】即时命中（射线）vs 物理投射（投掷物）两种风格。
  10. 【适用】狙击=射线、手雷/弓箭=物理、导弹=追踪。
  11. 【测试】射箭插墙、导弹追目标。
  12. 【注意】高速投掷物 Collision Detection 设 Continuous（第 93 课）。
  13. 【完成】投掷物体系完整！
✅
投掷物三型：抛物线（重力）、直飞（速度+碰撞）、追踪（每帧转向）。按需选用。
