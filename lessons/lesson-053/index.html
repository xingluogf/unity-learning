🚀课程导读

“重复做 N 次”是程序最擅长的。for 循环就是为此而生，比如生成 100 个敌人、遍历数组。

◆for 循环语法

三句话一个循环。

  1. 语法：for (初始化; 条件; 更新) { 循环体 }
  2. 三个部分：① 初始化（声明计数变量，如 int i = 0）；② 条件（满足才继续，如 i < 10）；③ 更新（每轮后执行，如 i++）。
  3. 执行流程：初始化 → 检查条件 → 执行循环体 → 更新 → 再检查条件……直到条件为 false 退出。
  4. 例：for (int i = 0; i < 5; i++) { Debug.Log(i); } 输出 0,1,2,3,4（共 5 次）。
  5. 注意 i 从 0 开始、条件用 < 而不是 <=，这是“半开区间”习惯。
  6. i 只在循环内有效（作用域）。
  7. 可以在循环体里用 i 做计算：Debug.Log(i * 2);
💡
i < 5 意味着执行 5 次（0~4）。想执行 N 次就写 i < N。

◆Unity 实战：批量生成物体

用 for 一次性创建一排方块。

  1. 新建脚本 ForDemo，挂到空对象上。
  2. 在 Start 里写：for (int i = 0; i < 10; i++) { GameObject cube = GameObject.CreatePrimitive(PrimitiveType.Cube); cube.transform.position = new Vector3(i * 2f, 0, 0); }
  3. 【解释】：每次循环创建一个方块，位置沿 X 轴每隔 2 米排开。
  4. 保存播放：场景里出现一排 10 个方块！
  5. 这是“动态生成”的雏形，正式实例化 Instantiate 在第 76 课。
  6. 试试改成 i * 3f 或加 Y 方向，观察变化。
  7. 【常见变形】：倒序 for (int i = 9; i >= 0; i--)、偶数步长 i += 2。
✅
for + 批量创建是游戏开发的黄金组合：生成敌人、子弹、地形全用它。

⚠常见错误与排查

⛔
错误：循环不结束（死循环）？
原因：更新语句缺失或条件恒真
解决：确认有 i++ 更新且条件最终会不满足；否则程序卡死（Update 里尤其危险）。
