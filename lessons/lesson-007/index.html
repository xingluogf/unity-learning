◆六大核心区域

Unity 编辑器主要由 6 个面板组成，它们的布局如图（各版本大致相同）。

  1. 【工具栏 Toolbar】位于最顶部：包含播放/暂停/停止按钮、撤销重做、场景/游戏视图切换、图层选择等，是“遥控器”。
  2. 【层级 Hierarchy】位于左上：列出当前场景里所有对象，相当于“目录”。点击对象，右侧会显示它的属性。
  3. 【场景视图 Scene View】位于中间偏左：3D 编辑空间，在这里摆放、旋转、缩放对象，是“工作台”。
  4. 【游戏视图 Game View】在场景视图旁边（点击标签可切换）：运行时玩家看到的效果，是“成品预览”。
  5. 【检查器 Inspector】位于最右侧：显示选中对象的所有组件与属性，是“属性面板”。
  6. 【项目窗口 Project】位于底部：管理项目所有资源文件（脚本、模型、贴图、场景等），是“仓库”。
  7. 【控制台 Console】常与项目窗口并列：显示运行日志、警告、报错，是“体检报告”。
  8. 主视图顶部还有一个搜索栏和标签页系统，可自由拖动面板改变布局。
💡
大胆拖动面板：Unity 布局可随意自定义，别怕弄乱，第 19 课教你一键恢复布局。

◆它们如何协作

用一个例子串起来：我要把方块变成红色。

  1. 在【Hierarchy】里点击选中 Cube 对象。
  2. 右侧【Inspector】立即显示该对象的组件，找到【Mesh Renderer】组件的 Material 属性。
  3. 在【Project】窗口里创建一个材质，改颜色为红色。
  4. 把红色材质拖到 Inspector 的 Material 槽里。
  5. 【Scene】视图里方块立即变红，点工具栏【▶ 播放】后【Game】视图里同样变红。
  6. 体验一次完整流程，你会发现所有操作都在这几个面板间来回切换。
✅
记住口诀：Hierarchy 选对象 → Inspector 改属性 → Project 找资源 → Scene 摆位置 → Game 看结果。

⚠常见错误与排查

⛔
错误：我的某个面板不见了？
原因：不小心关掉了
解决：菜单栏 Window（窗口）菜单里可以重新打开任意面板，例如 Window→General→Hierarchy。
