把特效章所有能力整合成一个“火球术”技能：发射、爆炸、光效、屏幕反馈。特效综合练习！

◆火球术特效设计

三阶段特效。

  1. 【阶段规划】火球技能 = 发射（飞行火球）→ 命中（爆炸）→ 反馈（光效+屏幕闪）。
  2. 【火球本体】球体 + 发光材质（Emission 橙红）+ 点光（跟随移动）。
  3. 【拖尾】火球挂一个 Trail Renderer 或粒子拖尾（Trails 模块，第 187 课）。
  4. 【飞行粒子】火球上加“小火花粒子”（圆锥小喷，朝后）。
  5. 【挂预制体】把火球+光+粒子打包成预制体 Fireball（第 76 课）。
  6. 【注意】火球是“抛射物”，用刚体+速度推进（第 91-93 课）。
💡
技能特效规划：发射态（飞行火花）+ 命中态（爆炸）+ 反馈态（光/屏闪）。三段式设计。

◆爆炸与反馈

命中的“高潮”。

  1. 【爆炸粒子】预制体 Explosion：一次性爆发粒子（Burst 100、速度向外、橙黄→红→灰）、Size 从小爆大、Noise 扭曲。
  2. 【冲击波】环形粒子（Circle 发射、径向向外）+ 光晕贴图扩散。
  3. 【灯光脉冲】命中处 Point Light 高亮→快速衰减：
  4. IEnumerator LightPulse() { light.intensity = 5f; while (light.intensity > 0.2f) { light.intensity -= Time.deltaTime * 8f; yield return null; } }
  5. 【地面烟尘】命中点烟雾粒子（灰、慢速、大寿命）。
  6. 【屏幕反馈】命中时调用 DamageFlash 闪白 + 相机震动（第 198 课）+ 爆炸音效（第 173 课）。
  7. 【触发实现】火球命中碰撞体时：实例化 Explosion 预制体 → 播放爆炸音效 → 闪屏 → 销毁火球。
  8. 【销毁】命中后 Destroy(fireball)；爆炸粒子可延迟销毁。
  9. 【注意】爆炸粒子若持续存在会占资源，延时销毁（Destroy(explosion, 3f)）。
  10. 【完成】你的“火球术”完整出炉！
✅
爆炸 = 爆发粒子 + 冲击环 + 光脉冲 + 烟尘 + 屏幕反馈。多感官同时爆发。

⚠常见错误与排查

⛔
错误：爆炸粒子一直存在？
原因：没销毁或没设生命周期
解决：爆炸预制体用一次性（不循环）并 Destroy(explosion, 3f)。
