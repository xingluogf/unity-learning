🚀课程导读

Animation 片段做出来了，怎么“按需播放”？靠 Animator Controller 状态机。本课搭起这个“指挥中心”。

◆Animator 组件

挂在角色上的“播放器”。

  1. Animator 组件负责播放动画，挂在要动画的对象上（角色、UI、机械）。
  2. 【添加】选中对象 → Add Component → 搜 Animator → 添加。
  3. 【Controller 槽】必须关联一个动画控制器（Animator Controller 资产）。
  4. 【Avatar 槽】人形动画（Humanoid）需要 Avatar（第 138 课）；通用动画可不填。
  5. 【Apply Root Motion】是否应用根运动（第 140 课）。
  6. 【Update Mode】Normal（每帧）、Animate Physics（配合物理）、Unscaled Time（不受暂停影响）。
  7. 【Culling Mode】Always Animate（始终动画）、Cull Update Transforms（画面外不更新，省性能）。
💡
Animator 组件 = 硬件；Controller 资产 = 软件。两者配合才能播动画。

◆创建 Animator Controller

搭建状态机雏形。

  1. 在 Project 右键 → Create → Animator Controller，命名 PlayerAnim。
  2. 【双击打开】双击该控制器，打开 Animator 窗口（状态机视图）。
  3. 【默认结构】自动有 Entry（入口）与 Any State（任意状态）两个灰色节点。
  4. 【添加状态】右键空白处 → Create State → Empty，创建“Idle”状态；重复创建“Walk”“Jump”等。
  5. 【绑定片段】选中 Idle 状态，在 Inspector 的 Motion 槽里拖入你的动画片段（.anim）。
  6. 【入口连接】默认 Entry 会自动连到第一个状态；也可右键 Entry → Make Transition 连到指定状态。
  7. 【初始状态】绿色边框的状态是默认状态（播放时最先进入）。
  8. 【保存】控制器自动保存（Ctrl+S）。
  9. 【挂载】把 PlayerAnim 拖到角色的 Animator → Controller 槽。
  10. 播放：角色播放初始状态的动画。
✅
状态机三要素：状态（State 节点）、过渡（Transition 箭头）、参数（Parameters）——下一课逐一展开。

⚠常见错误与排查

⛔
错误：角色不播放动画？
原因：Controller 未挂载、或状态没有 Motion、或默认状态未连接
解决：确认 Animator 的 Controller 已关联；状态有 Motion；Entry 连到了某状态。

  • 创建 Idle/Walk 两个状态并绑定动画
