🚀课程导读

从零做一个 2D 游戏：先搭好“2D 环境”。本课创建项目并理解 2D 与 3D 的区别。

◆创建 2D 项目

选对模板。

  1. 【创建】Unity Hub → New Project → 选【2D Core】模板（2D 模板预置了 2D 设置）。
  2. 【命名】输入项目名，如 My2DGame，选择保存位置，创建。
  3. 【2D 模板特点】默认场景自带相机（正交）、光源、2D 渲染设置。
  4. 【若已是 3D 项目】Edit → Project Settings → Editor → Default Behavior Mode 改 2D（进阶）。
  5. 【目录规划】按第 4 章规范建文件夹：Scenes、Scripts、Sprites、Audio 等。
  6. 【场景】File → New Scene → 选 Basic 2D，保存为 Main。
  7. 【了解 2D 视图】2D 模式下 Scene 视图正面看场景（Toggle 2D 按钮切换）。
  8. 【注意】2D 模板用 URP 2D Renderer，光照基于精灵（Sprite-Lit Default）。
  9. 【准备】准备几张测试精灵图（第 202 课）。
  10. 【完成】2D 项目环境就绪！
💡
2D 与 3D 最大区别：2D 用精灵图（Sprite）+ 正交相机 + 2D 物理。选对模板省一半事。

◆正交相机设置

2D 的“眼睛”。

  1. 【正交 vs 透视】2D 用正交投影（Orthographic）：无近大远小、物体不变形。
  2. 【检查相机】选中 Main Camera，Projection 应为 Orthographic。
  3. 【Size】相机 Size 决定“看到的世界高度的一半”（Size=5 → 上下各 5 单位）。
  4. 【调整】Size 小=看得近（物体显得大）；Size 大=看得远。
  5. 【背景】Camera 的 Background 设天空色/纯色。
  6. 【分辨率】Game 视图分辨率决定可视宽高比（竖屏手游设 9:16）。
  7. 【安全区】竖屏游戏注意 UI 安全区（第 158 课）。
  8. 【像素单位】1 单位=多少像素由精灵 PPU 决定（第 202 课）。
  9. 【预览】运行前切 2D 视图确认场景内容在相机视野内。
  10. 【注意】2D 相机通常不旋转、不缩放（跟随时用代码平移，第 216 课）。
✅
正交相机 = 2D 标准：Projection Orthographic + Size 调视野 + 背景色。

⚠常见错误与排查

⛔
错误：场景物体显示不出/大小不对？
原因：相机 Size 或物体位置超出视野
解决：调整相机 Size；把物体放在 (0,0,0) 附近；检查 2D 视图。
