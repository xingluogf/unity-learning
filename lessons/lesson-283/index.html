🚀课程导读

“浏览器直接玩”的网页版游戏——WebGL。适合分享、展示、独立游戏平台。

◆WebGL 配置

网页版设置。

  1. 【选平台】Build Settings → WebGL。
  2. 【首次】提示安装 WebGL Build Support（Hub 勾选/Install）。
  3. 【Player Settings】
  4. Compression Format：Brotli（推荐，体积小）。
  5. WebGL 内存设置：根据游戏需求调（Loading 里）。
  6. 【构建】点 Build，输出一个网页文件夹（index.html + Build/）。
  7. 【产物】用浏览器打开 index.html 即可玩。
  8. 【本地测试】直接双击 index.html 可能因浏览器安全限制加载失败——用本地服务器测试（下）。
  9. 【服务器】部署到任意静态网站托管（itch.io/Netlify/GitHub Pages）。
  10. 【注意】WebGL 无法访问本地文件（存档用浏览器存储）。
  11. 【完成】网页版“能跑”。
  12. 【说明】WebGL 是“浏览器里的 Unity”：跨平台、免安装。
💡
WebGL = 网页版：浏览器即玩。压缩用 Brotli、测试用本地服务器。

◆部署与分享

“发链接”。

  1. 【本地测试服务器】用 Python 起服务：
  2. 在构建文件夹目录运行：python -m http.server 8080
  3. 浏览器打开 http://localhost:8080
  4. 【itch.io 上传】itch.io 支持 WebGL 直接上传（网页游戏专区）。
  5. 【GitHub Pages】仓库开 Pages 托管静态网页。
  6. 【Netlify】拖文件夹即部署（简单）。
  7. 【分享链接】把部署后的网址发给朋友即可玩。
  8. 【注意】“浏览器安全”：跨域/本地文件限制要服务器环境。
  9. 【性能】WebGL 性能低于原生（优化更重要，第 271-272 课）。
  10. 【兼容】不同浏览器表现略有差异（测 Chrome/Edge）。
  11. 【完成】网页版“上线”！
  12. 【推荐】独立游戏/游戏 jam 首选 WebGL 发布。
✅
WebGL 分发 = 本地服务器测试 → 拖到平台托管 → 发链接。三步上线。

解决：用 python -m http.server 起本地服务器访问，或直接部署到托管平台。
