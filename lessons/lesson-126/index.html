🚀课程导读

动画让游戏“活”起来。Unity 动画体系主要由两部分组成：Animation 窗口做“片段动画”，Animator 做“状态切换”。本课建立整体地图。

◆动画系统的两大组件

先分清“做动画”和“管动画”。

  1. 【Animation 窗口】Window → Animation → Animation：制作“关键帧动画”，像剪辑师逐帧摆姿势，输出一个动画片段（Animation Clip）。
  2. 【Animator 组件】给角色添加 Animator 组件，关联一个“动画控制器（Animator Controller）”，负责“什么时候播哪个动画”。
  3. 【Animator Controller】Window → Animator 打开：可视化的“状态机”，用状态+过渡管理动画切换。
  4. 【流程】用 Animation 窗口做好若干片段 → 在 Animator Controller 里组织状态机 → 挂到角色 Animator 上 → 代码控制参数切换。
  5. 【动画片段来源】① Animation 窗口自做；② 外部 FBX 模型自带；③ 商店资源。
  6. 【组件】Animator 组件：Controller 槽放控制器、Avatar 槽放骨骼配置。
  7. 【播放控制】默认自动播放 Entry 连出的状态；用代码 SetFloat/SetTrigger 等控制切换（第 142 课）。
💡
记忆：Animation 窗口 = 拍素材；Animator 状态机 = 剧本编排。

◆打开两个窗口

把工具调出来。

  1. 【打开 Animation】菜单 Window → Animation → Animation（或 Ctrl+6 快捷键）。
  2. 【打开 Animator】菜单 Window → Animation → Animator。
  3. 【布局】把两个窗口拖到方便的位置（第 19 课布局技巧）。
  4. 【Animation 窗口布局】左侧对象列表、中间时间轴、下方关键帧区域。
  5. 【Animator 窗口布局】左侧参数（Parameters）、中间状态图（Base Layer）、左侧 Layers 层级。
  6. 先认识界面即可，本课不需要做内容。
  7. 【注意】Animation 窗口在“非播放”状态编辑，播放状态看效果。
  8. 【版本】TextMeshPro、新 UI 等也会用到动画，先掌握基础。
💡
两个窗口快捷键：Animation 是 Ctrl+6，Animator 在 Window→Animation 菜单里。

⚠常见错误与排查

⛔
错误：Animation 窗口打不开？
原因：可能被其他窗口遮挡
解决：Window → Animation → Animation 强制打开；检查标签页。
